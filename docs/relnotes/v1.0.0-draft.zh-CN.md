Adreno 690 硬件 Vulkan。

## 安全公告：v0.7.1 及更早版本的网络 adb

**v0.7.1-alpha 及之前的每一个版本，都能让同一网络里的任何人接管这台机器。** 那些镜像在所有网卡上
（包括你开的热点）监听 TCP 5555 端口的 adb，连接时**不弹**"允许 USB 调试吗？"的授权框；镜像是可调试的
（`adb root` 就能拿到 root shell）；镜像里还带着维护者的 adb 公钥。

从本版起，发布版：

* 不再监听 5555 端口，adb 默认**关闭**，要你自己在开发者选项里打开；
* 每台电脑都要你授权（`ro.adb.secure=1`）；
* 不可调试（`ro.debuggable=0`），不再有 `adb root`；
* 不带维护者的公钥。

更新后自动生效，不用做什么：原来的 5555 设置是镜像内置的默认值，Android 不会把这种默认值存进 `/data`。
**例外是自己运行过 `setprop persist.adb.tcp.port …` 的人** —— 那个值存在 `/data` 上，更新后还在。
怎么清掉它，会补在已知限制页面里（⬜ 待上机核实）。

用 adb 的话还要知道：

* 更新之后，网络 adb 会连不上，直到你设置好*无线调试*（配对码）或者通过 USB 给电脑授权。
* **已授权的电脑仍然直接拿到 root shell**：系统内置了 root（KernelSU / ReSukiSU），即使不可调试，
  `adb shell` 也经它以 root 运行。只给你信任的电脑授权。
* *USB 调试*每次重启都会自己变回关闭（⬜ 待上机确认）。

## 启动入口、自动回退与 fastboot

**Android 有了自己的启动器 gk3boot**，由 systemd-boot 作为默认项 `Android` 启动。它读 Android 存在 `misc`
里的 A/B 状态、选出槽，直接从那个槽的 boot 分区启动内核 —— 也就是手机上 bootloader 干的活。
它在装上 1.0 后的第一次开机完成之后接手（那第一次开机仍然走旧的、按槽的条目）。本版默认打开。

* **更新坏了会自己退回。** 刚更新的槽有六次机会；如果始终没能开机完成，gk3boot 会退回上一个槽，
  Android 弹出"已自动退回旧版本"。在这台机器上用一个故意弄坏、连续 panic 六次的更新测过。
  卡死不动、也不重启的情况，仍然要长按电源键。
* **启动器自己坏了也锁不住你。** `Android` 条目连续三次启动失败，systemd-boot 就回落到旧的按槽条目。在本机测过。
* **fastboot。** `adb reboot bootloader`、`adb reboot fastboot`，或者开机菜单里的 `Android fastboot / boot menu`，
  会启动一个小的 fastboot 环境（数据线插靠近电源键的 USB-C 口）。在本机核对过：`fastboot devices`、`fastboot getvar all`、
  `fastboot oem device-info`、`fastboot reboot`、`fastboot reboot bootloader`、菜单里的音量键，以及
  `adb reboot bootloader / fastboot / recovery` 都会进到这里、之后挂着的请求会被清掉。

还没在本机上测过：

* `fastboot flash`（已实现，模拟器测试通过）—— 目前请改用图形安装器重新安装。
* 在 fastboot 模式里用电源键确认菜单项。
* **经这条路恢复出厂**（见"已知问题"）。
* 双系统：把 Windows 设成默认系统，以及设置里新的*启动选项*页上的"重启到 Windows"。
* 从 0.7.x 升上来的机器第一次切换过来的那一跳。

关掉它：以 root 身份 `setprop persist.vendor.gaokun3.gk3boot off`，重启一次；之后机器和 1.0 之前完全一样地启动。

## 内核：7.2.9 稳定版

内核从 7.2 的候选版（7.2-rc2）换成 **7.2.9 稳定版**，我们的补丁都带了过去。稳定版里有一个改动弄坏了这台机器的屏幕 ——
这块面板的两半是一起驱动的，而 7.2.6 撤掉了恰好针对这种接法的一个修复，面板就不亮了。我们把那次撤销再撤回来。

在这个内核上测过：显示、前后摄像头、硬件视频解码（一个构建 15/15，另一个 13/15 —— 见"已知问题"）、
待机与唤醒 11/11、每次 Wi-Fi 都能回来。

## Wi-Fi

* **MAC 地址固定了。** 以前 Wi-Fi 芯片每次开机都换一个新 MAC，路由器每次都当成"新设备"。现在地址由 SoC 的序列号派生，
  重启不变（本地管理地址）。它会和你更新前的地址不同一次 —— 如果路由器给旧地址保留了 IP，请改一下保留规则。
  1.0 和以前一样**不开**按网络随机的 MAC：每个网络看到的都是同一个设备地址。（⬜ 还没在真机上测过）
* **热点和 Wi-Fi 应该能同时开了** —— 驱动一直支持，是软件配置不支持。（⬜ 还没在真机上测过）
* 热点可以选 **5 GHz 和 WPA3**。（⬜ 还没在真机上测过）
* 联网检测加了国内能访问的备用地址。（⬜ 还没在真机上测过）
* 对时先试 `ntp.aliyun.com`，失败后会一直重试；在本机测过。

## 电池与待机

* **设置里有了待机开关。** *设置 → 电池 → 待机（睡眠）*里的"允许待机"，不用 root shell 就能开关待机。（⬜ 还没在真机上测过）
* **充电上限（实验性）。** *设置 → 电池 → 充电控制*可以经华为的嵌入式控制器（EC）把电量保持在 70–80%。
  （⬜ 还没在真机上测过；EC 到达上限时具体怎么表现，我们还没核对。）
* **按应用统计耗电**：加了这台机器的功耗参数表，设置里能估算各个应用用了多少电。表里的部件电流是估算值。（⬜ 还没在真机上测过）
* **待机时 Wi-Fi 保持连接**（PR #40）：以前每次待机都断开 Wi-Fi、给芯片断电，醒来再重新连。现在网络上来的数据仍然叫不醒机器，
  消息要等系统下一次定时唤醒才到（见已知问题）。待机中如果断线，会在息屏状态下自己连回来；固件偶尔拒绝进入待机模式时，
  这一次待机推迟一两秒重试，不再断开连接（PR #46）。（⬜ 还没在发版构建上测过）
* **Wi-Fi 固件崩溃后能自己恢复**，包括在待机中崩溃的情况；以前可能直接内核崩溃，或者到下次冷启动前 Wi-Fi 都起不来（PR #44）。（⬜ 还没在发版构建上测过）
* **音频 DSP 在待机时能睡下去了**，内存在待机时也能降频（主线 7.3 的 5 个补丁，PR #46）。（⬜ 还没在发版构建上测过）
* **息屏且没有应用需要时，传感器会停下来**；以前传感器 DSP 一直醒着。在本机测过。
* 后台应用限制在四个小核上（Cortex-A78C，cpu0–3）；前台应用仍然可以用全部八个核。（⬜ 还没在真机上测过）
* EC 报的电池状态解码得更细了（多了电量等级）。测过新值能出来；"弱充电器上显示充电、电量却在掉"有没有因此修好，还没测。

## USB 与存储

* USB-C 口进入异常状态，或者平板反过来给电脑供电时，会弹通知告诉你重插或重启。（⬜ 还没在真机上复现过）
* 插在靠近电源键那个口上的鼠标或 U 盘，息屏后应该保持连接。（⬜ 还没在真机上测过）
* `/data` 现在给系统留了一小块保留空间（128 MiB），盘写满了也不会让 Android 起不来。在本机测过。
* **电源键旁边的口恢复 USB 3 速度**；它需要的一路电源保持常开，修好了"作为 USB 设备时进待机就整板复位"。这个口的角色（主机或设备）按插入的东西决定，
  由 USB 端口服务负责；待机中插拔会唤醒机器；USB-C 控制器驱动（UCSI）修了几处。贡献者测过，发版构建上还没接外设测。

## 手写笔与触摸

* **华为 M-Pencil 能用了**（压感、悬停、倾斜、侧面双击）：触摸屏的第二颗控制芯片有了驱动。贡献者测过，发版构建上还没拿真笔测。
* **手掌识别**：事后发现属于手掌的触点会被撤回（App 收到的是*取消*）。游戏触摸预设会关掉它。贡献者测过。

## 游戏

* **《英雄联盟手游》打开不再立刻退出**（能进到用户协议页面；能不能打完一局没测）：内核现在默认只分配 2^39 以下的内存地址，这个游戏依赖这一点。
* **应用读到一个伪装的内核版本** `6.6.30-android15-8-…`，因为有些环境检测只接受 6.x 及更早的版本；实际跑的是 Linux 7.2.9。
  系统的其他部分显示的是真实版本，但应用的崩溃记录里是伪装的版本。在"设置 → 系统 → 内核版本伪装"里可以关闭或改成别的版本。
  不要用 KernelSU 管理器的"安装" / LKM 修补：KernelSU 已经编进内核了。
* 普通 App 读不到 Wi-Fi 网卡的硬件 MAC 地址和局域网里其他设备的列表了；大型 OpenGL ES 游戏两次运行之间能留住更多的着色器缓存。

## 音频

* **给游戏的低延迟输出**：请求低延迟的游戏走 Android 的快速混音通路，在开发构建上量到的输出延迟从约 317 ms 降到约 110 ms。

## 小改动

* **后摄隐私灯**：后摄工作时，摄像头的白色指示灯会亮，停下就灭。在本机测过。
* **键盘盖**：合上键盘盖会熄屏，打开就唤醒，翻到背面不受影响。
* 开机后一开始就能报出正确的合盖状态（开着盖、合着盖开机都测过）。
* 检查 OpenGL ES 3.2 的应用现在能看到它；系统不再声称有指南针；加速度计和陀螺仪报的是实际的 50 Hz。
* 系统更新会清掉 EFI 分区上用不到的文件，给以后的更新留出空间（测试机上可用空间 87 → 104 MB）。
* 项目版本号可以用 `getprop ro.vendor.gaokun3.version` 读到。
* 内核的 hung task 看门狗这次真的打开了（120 秒）。
* 背光写入失败不会再让系统界面崩溃。（原来的崩溃没有刻意复现）
* 音频 / 蓝牙卡死看门狗会记下更多证据（播放停滞、DSP 状态变化）。
* 系统更新页面上"更新日志""下载"的链接改指国内能访问的镜像站。（⬜ 还没在设备上点过）
* 图形设备节点不再对所有人可写。

## 已知限制

完整清单和应对办法见 **[docs/known-limitations.zh-CN.md](https://github.com/vahiru/gaokun-android/blob/main/docs/known-limitations.zh-CN.md)**
（[English](https://github.com/vahiru/gaokun-android/blob/main/docs/known-limitations.md)）。简要来说：

* **安全**：用 Android 公开的测试密钥签名；`/data` **没有加密**；内置 root（KernelSU / ReSukiSU），任何你授权了 adb 的电脑都能拿到 root shell；
  SELinux 是 `enforcing`（手工分区的硬盘可能要改 EFI 分区的名字）；内核对外报告伪装的版本号；启动链未上锁。v0.7.1 及以前免授权的网络 adb：见上面的安全公告。
* **随镜像分发的专有组件**：华为固件与传感器配置、华为 Histen 音频引擎、Google 应用（MindTheGapps）。
* **不支持**：设置里的"清除所有数据"（见"已知问题"；请用图形安装器的*重新安装 Android*）；USB 传文件（MTP）；U 盘；
  指纹（开发中）；自动亮度；GPS / 定位；DRM 视频（没有 Widevine）；通话时蓝牙耳机和有线耳机的麦克风；
  待机时的消息推送；Google 认证（登记一次即可；Play Integrity 永远过不了）；没有国内应用商店；没有蜂窝网络；没有指南针。
* **其它问题**：长时间运行后音频和蓝牙可能一起卡死；插电脑时平板可能反过来给电脑充电；USB-C 口回插后可能坏掉、直到重启；
  手写笔与手掌识别有了驱动、但还没在发版构建上核对；《英雄联盟手游》能不能打完一局没测；用低功率电源时显示"正在充电"、电量却在掉。中文输入法（fcitx5）已预装，但要在设置里自己打开一次。
  <!-- D10：2026-10-06 用户定从 GitHub 取 fcitx5-android 0.1.3，dev.9 之后的构建起带（f2fd400）。⬜ 定稿前确认发版构建里真有它、实体键盘中英切换。 -->
  打开热点会断开 Wi-Fi —— 如果真机测试通过，本版已修好（⬜ 还没测）。
