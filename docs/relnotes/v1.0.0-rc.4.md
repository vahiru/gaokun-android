> ### Upgrade and installation notes
> * **System update (OTA)**: users on `v0.7.1-alpha` through `v1.0.0-rc.3` can update directly under *Settings → System → System update*. Back up important data beforehand: once the new build boots successfully, rolling back to the previous version with user data kept is not supported. If updating from `v1.0.0-rc.2` or earlier, read the [v1.0.0-rc.3 release notes](https://github.com/vahiru/gaokun-android/blob/v1.0.0-rc.4/docs/relnotes/v1.0.0-rc.3.md) first for the Android 16 → 17 data upgrade and the one-time firmware crash-record cleanup ([#56](https://github.com/vahiru/gaokun-android/issues/56)).
> * **BOE panel models**: a single image now detects BOE and CSOT panels automatically — **do not** replace the device tree manually after updating.
> * **Fresh installation**: to install dual-boot directly from Windows 11 without a USB drive, use [Windows installer 0.1.0](https://github.com/vahiru/gaokun-android/releases/tag/windows-installer-v0.1.0); for other installation modes and requirements, see the [installation guide](https://github.com/vahiru/gaokun-android/blob/v1.0.0-rc.4/docs/INSTALL.md), [known limitations](https://github.com/vahiru/gaokun-android/blob/v1.0.0-rc.4/docs/known-limitations.md), and [FAQ](https://github.com/vahiru/gaokun-android/blob/v1.0.0-rc.4/docs/FAQ.md).

## Camera

* **Hardware ISP** ([#120](https://github.com/vahiru/gaokun-android/pull/120); initial IFE pixel-path implementation by **@dezige131**): image processing now runs on Qualcomm's IFE hardware ISP, reaching up to 60 fps in rear binned mode (30 fps for full-resolution rear and front), substantially lowering viewfinder CPU usage, and eliminating viewfinder freezes when taking photos; adds digital zoom, phase-detection autofocus with contrast refinement, exposure compensation, AE/AWB lock, manual exposure and focus, white balance presets, 50/60 Hz anti-banding, still-photo denoising, and EXIF thumbnails.
* **Auto-exposure and colour improvements** ([#86](https://github.com/vahiru/gaokun-android/pull/86), [#87](https://github.com/vahiru/gaokun-android/pull/87), [#126](https://github.com/vahiru/gaokun-android/pull/126)): small bright highlights in the background (such as lamps or windows) no longer darken the entire frame; fixed periodic brightness pulsing on the front camera in dim light; added per-camera colour calibration and Bayesian auto white balance.
* **Orientation and app compatibility** ([#83](https://github.com/vahiru/gaokun-android/pull/83), [#87](https://github.com/vahiru/gaokun-android/pull/87), [#115](https://github.com/vahiru/gaokun-android/pull/115); [#42](https://github.com/vahiru/gaokun-android/issues/42), thanks to **@mashen11**): fixed front and rear cameras rotated by 90°, Aperture crashing when switching to video mode, and Camera1 apps such as QQ failing to open the camera; raised Camera1 video recording to 1080p.

## Standby and networking

* **Deep standby and charger wake** ([#80](https://github.com/vahiru/gaokun-android/pull/80), [#90](https://github.com/vahiru/gaokun-android/pull/90), [#93](https://github.com/vahiru/gaokun-android/pull/93), [#95](https://github.com/vahiru/gaokun-android/pull/95)): the SoC and memory now enter low-power states during sleep, reducing screen-off standby draw to ~0.5 W; plugging in a charger during sleep now wakes the system; removed the earlier experimental standby toggle page from Settings.
* **FCM push wake-up in standby** ([#81](https://github.com/vahiru/gaokun-android/pull/81), [#88](https://github.com/vahiru/gaokun-android/pull/88), [#89](https://github.com/vahiru/gaokun-android/pull/89)): incoming packets from Google's push servers now wake the system so apps using FCM deliver notifications promptly while asleep; fixed losing the Wi-Fi connection when entering sleep.
* **Reliability fixes** ([#73](https://github.com/vahiru/gaokun-android/pull/73), [#76](https://github.com/vahiru/gaokun-android/pull/76), [#77](https://github.com/vahiru/gaokun-android/pull/77), [#79](https://github.com/vahiru/gaokun-android/pull/79)): hardened Wi-Fi firmware crash recovery and stopped firmware crashes while Wi-Fi is disabled from keeping the tablet awake an extra minute on every wake-up; shortened NTP timeout; fixed sensors stopping after ~6 hours of standby; prevented an internal USB controller failure from blocking sleep.

## Display and video

* **Automatic panel detection and factory colour calibration** ([#58](https://github.com/vahiru/gaokun-android/pull/58), [#61](https://github.com/vahiru/gaokun-android/pull/61), [#114](https://github.com/vahiru/gaokun-android/pull/114)): a single image supports both BOE and CSOT panels automatically; loads each unit's factory 3D LUT calibration from firmware, enables Display P3 wide colour and 10-bit output, and adds **Vivid** (default) and **Standard** modes under *Settings → Display → Colors*.
* **HDR video playback** ([#62](https://github.com/vahiru/gaokun-android/pull/62), [#65](https://github.com/vahiru/gaokun-android/pull/65)): supports HDR10 and HLG playback with automatic brightness boost for highlights (because the LCD backlight has no local dimming, dark areas also lift when brightness rises).
* **10-bit hardware decoding and playback fixes** ([#59](https://github.com/vahiru/gaokun-android/pull/59), [#60](https://github.com/vahiru/gaokun-android/pull/60)): added HEVC Main10 and VP9 Profile 2 hardware decoding and display; fixed mpv-based players (such as PiliPlus) falling back to software decoding, decoder service crashes, hardware decoding staying unavailable until a restart after a decoder watchdog reset, and 8 extra lines at the bottom of 1080p video.
* **Hardware video encoding** ([#116](https://github.com/vahiru/gaokun-android/pull/116), [#118](https://github.com/vahiru/gaokun-android/pull/118), [#106](https://github.com/vahiru/gaokun-android/issues/106)): enabled H.264 / HEVC hardware encoding for camera recording, `screenrecord` and in-app video processing. *Note: only one stream uses hardware encoding at a time (the built-in screen recorder at 120 Hz still uses software encoding), and continuing to record, export or compress video after the screen turns off may hang the video hardware — keep the screen on while encoding.*
* **Window blur and landscape boot** ([#57](https://github.com/vahiru/gaokun-android/pull/57), [#82](https://github.com/vahiru/gaokun-android/pull/82)): restored background blur on the lock screen, notification shade and Quick Settings; set the boot animation and initial post-boot orientation to landscape.

## Audio

* **Microphone array, echo cancellation and NPU noise suppression** ([#70](https://github.com/vahiru/gaokun-android/pull/70), [#84](https://github.com/vahiru/gaokun-android/pull/84)): fixed impulse noise, start-of-recording clicks and missing low frequencies on the built-in microphones and raised capture gain; enabled multi-microphone beamforming for stereo capture; added speakerphone echo cancellation and NPU noise suppression for voice and video calls (enabled by default for calls and disabled for recordings, configurable per scenario under *Settings → Sound & vibration → Microphone noise suppression*).
* **Lower latency and wired headphone fix** ([#110](https://github.com/vahiru/gaokun-android/pull/110), [#117](https://github.com/vahiru/gaokun-android/pull/117), [#119](https://github.com/vahiru/gaokun-android/pull/119)): reduced game audio latency by ~32 ms; fixed quiet signals on wired headphones being boosted by ~20 dB.

## Touch, stylus and keyboard cover

* **Stylus accuracy and settings** ([#67](https://github.com/vahiru/gaokun-android/pull/67), [#74](https://github.com/vahiru/gaokun-android/pull/74), [#75](https://github.com/vahiru/gaokun-android/pull/75), [#78](https://github.com/vahiru/gaokun-android/pull/78); CSOT calibration contributions from **@Rivarise** in [#63](https://github.com/vahiru/gaokun-android/pull/63)): reduced diagonal wobble and kinks, fixed inward stroke drift near the left and right edges on CSOT panels, and added *Settings → Connected devices → Stylus settings* with four ink-smoothing levels and configurable double-tap action (toggle eraser, side-button click, or disabled).
* **Touch response** ([#68](https://github.com/vahiru/gaokun-android/pull/68), [#124](https://github.com/vahiru/gaokun-android/pull/124)): reduced taps turning into short swipes and short flicks while lifting a finger being missed in rhythm games; reported touch-up immediately without a three-frame delay.
* **Keyboard cover sleep and wake** ([#71](https://github.com/vahiru/gaokun-android/pull/71), [#72](https://github.com/vahiru/gaokun-android/pull/72)): closing the cover turns the screen off, opening it wakes the tablet, alarm or network wake-ups while the cover is closed no longer light the screen, and the first key press after sleep wakes the screen directly.

## Fingerprint

* **Enrolment and screen unlock** ([#92](https://github.com/vahiru/gaokun-android/pull/92), [#123](https://github.com/vahiru/gaokun-android/pull/123)): fingerprints can be enrolled in Settings for screen unlock, supporting both Goodix and FocalTech sensors with proper temporary lockout cooldown after repeated failed attempts. Enrolment no longer has a 90-second time limit, so it completes once you have touched the sensor enough times. *Note: rated convenience class, so fingerprint payment in banking and payment apps is not supported; recognition parameters on models with a FocalTech sensor have not been calibrated yet, and many touches are rejected for image quality during enrolment, so enrolling one finger often takes thirty to forty touches (on one FocalTech unit, five screen unlocks after enrolment all succeeded) — if recognition is poor, unlock with your password and report it.*

## GPU and system

* **GPU stability and preemption** ([#112](https://github.com/vahiru/gaokun-android/pull/112), [#113](https://github.com/vahiru/gaokun-android/pull/113)): fixed a GPU driver null-pointer crash that an unprivileged app could trigger to reboot the device; enabled Adreno 690 preemption, substantially reducing system UI frame drops under heavy game load.
* **ReSukiSU manager can grant root**: the built-in ReSukiSU moves to `v4.2.0-rc3`, matching the interface version of the latest released manager. Before this, installing the current manager only showed "Kernel update required" and could not grant root to apps or the shell.
* **Per-app kernel version spoofing** ([#69](https://github.com/vahiru/gaokun-android/pull/69)): only regular apps read the disguised kernel version while Settings and `uname -r` show the real Linux version; can be disabled or customized under *Settings → System → Kernel version spoofing* (enabled by default).
* **Boot and peripheral fixes** ([#66](https://github.com/vahiru/gaokun-android/pull/66), [#53](https://github.com/vahiru/gaokun-android/pull/53), thanks to **@Rivarise**; [#96](https://github.com/vahiru/gaokun-android/pull/96), [#97](https://github.com/vahiru/gaokun-android/pull/97), [#98](https://github.com/vahiru/gaokun-android/pull/98), [#99](https://github.com/vahiru/gaokun-android/pull/99), [#121](https://github.com/vahiru/gaokun-android/pull/121), [#125](https://github.com/vahiru/gaokun-android/pull/125)): shortened the single-boot Android boot menu timeout to 5 s; fixed USB 2.0 on the port away from the power button stopping after Type-C reconfiguration; fixed battery temperature reading 0 °C; switched the system and USB/adb serial number to the device's real SMBIOS serial instead of `gaokun3`; enabled kernel BTF, `userfaultfd`, and `ISO9660` support for hybrid ISO LiveCD images; published the standalone USB-free dual-boot [Windows installer 0.1.0](https://github.com/vahiru/gaokun-android/releases/tag/windows-installer-v0.1.0).
