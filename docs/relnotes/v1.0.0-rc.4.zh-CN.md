适用于华为**MateBook E Go**（骁龙8cx Gen 3 / SC8280XP）的**Android 17（crDroid 13）**，运行在**主线Linux内核**上，Adreno 690支持硬件Vulkan。

**1.0的第四个候选版。**与1.0.0-rc.3相比：相机改用高通**IFE硬件ISP**，补齐1080p Camera1录像、数码变焦与曝光控制；SoC支持进入**深度待机**（约0.5 W），待机期间**FCM推送可唤醒系统**及时送达；屏幕加入**出厂3D LUT色彩校准**、**HDR视频提亮**，并支持**BOE与CSOT屏共用同一镜像**；视频加入**10-bit硬件解码**与**H.264 / HEVC硬件编码**；音频加入**四麦波束成形、通话回声消除与NPU降噪**，降低游戏音频延迟并修复有线耳机听感；**侧边指纹**可用于锁屏解锁；GPU修复了一处**可由普通应用触发的内核崩溃**并开启**Adreno 690抢占**。

## 相机

* **改用IFE硬件ISP**（[#120](https://github.com/vahiru/gaokun-android/pull/120)；IFE像素通路的最初实现来自**@dezige131**）：去马赛克、白平衡、色彩矩阵、伽马、缩放和对焦统计改由高通IFE硬件完成，原有的软件ISP路径已移除。
  * 后摄合并模式最高**60 fps**，后摄全尺寸与前摄为30 fps；拍照模式下预览与成片分两路输出，后摄全尺寸取景时相机服务的CPU占用约从单核48%降至21%，JPEG在独立线程中编码，按下快门时预览不再停顿。
  * 支持IFE数码变焦、相位对焦配合对比度精调（暗光下改用IFE对焦统计）、曝光补偿、AE/AWB锁定、手动曝光与手动对焦、白平衡预设、50/60 Hz防频闪、亮度锐化、拍照降噪，以及带缩略图的JPEG EXIF信息。
* **取景方向、帧率与Camera1兼容**（[#83](https://github.com/vahiru/gaokun-android/pull/83)、[#86](https://github.com/vahiru/gaokun-android/pull/86)、[#87](https://github.com/vahiru/gaokun-android/pull/87)、[#91](https://github.com/vahiru/gaokun-android/pull/91)、[#115](https://github.com/vahiru/gaokun-android/pull/115)；[#42](https://github.com/vahiru/gaokun-android/issues/42)，感谢**@mashen11**）：修正前后摄画面旋转90°的问题（已在2023款机器上验证，2022款有待核对）；前摄在室内光下预览保持30 fps；修复Camera1接口兼容性（QQ等应用可正常调用相机），并新增`media_profiles_V1_0.xml`，Camera1应用的录像规格由320×240提升至**1080p**。

## 待机与Wi-Fi

* **SoC进入深度待机**（[#80](https://github.com/vahiru/gaokun-android/pull/80)、[#90](https://github.com/vahiru/gaokun-android/pull/90)）：此前休眠期间AOSS、CX电源域和DDR均未进入低功耗状态。现在PCIe根端口可进入D3，蓝牙串口在休眠时释放时钟与投票，恢复时两个PCIe控制器并行重训练链路（NVMe失败自动重试），CPU集群申请下电被固件拒绝时等待3 ms再重试。测试内核上整夜待机实测约0.51 W（每小时耗电约1.2%）；合入后的版本只做过短测，整夜功耗有待重测。
* **待机时及时接收FCM推送**（[#81](https://github.com/vahiru/gaokun-android/pull/81)、[#88](https://github.com/vahiru/gaokun-android/pull/88)、[#89](https://github.com/vahiru/gaokun-android/pull/89)、[#93](https://github.com/vahiru/gaokun-android/pull/93)）：Wi-Fi可通过PCIe `WAKE#`唤醒系统，新增服务`gaokun3_wifiwake`按Google推送服务器地址配置收包唤醒规则，使用FCM的应用在息屏待机期间能及时收到消息；同时修复WoWLAN挂起途中丢失Wi-Fi链路的问题，并支持睡眠中插入充电器唤醒系统。
* **崩溃恢复与长待机修复**（[#73](https://github.com/vahiru/gaokun-android/pull/73)、[#76](https://github.com/vahiru/gaokun-android/pull/76)、[#77](https://github.com/vahiru/gaokun-android/pull/77)、[#79](https://github.com/vahiru/gaokun-android/pull/79)）：加固`ath11k`与`mac80211`的固件崩溃恢复，恢复途中再次崩溃不再关闭Wi-Fi；修复Wi-Fi关闭状态下固件崩溃后每次唤醒多停留一分钟的问题；NTP单地址超时从5秒缩短至2秒；修复冻结进程时泄漏FastRPC上下文导致待机约6小时后`hexagonrpcd-sdsp`（传感器服务）无法启动的问题；内部xHCI USB控制器失效后不再阻断整机挂起。

## 显示与视频

* **BOE与CSOT屏共用同一镜像**（[#58](https://github.com/vahiru/gaokun-android/pull/58)）：内核按主板面板ID引脚（`GPIO102` / `GPIO91`）识别面板型号，BOE屏机器无需再单独替换设备树。（已在BOE屏上验证；CSOT屏读回`0 0`符合硬件定义，仍待在CSOT机器上实测确认。）
* **出厂色彩校准与颜色模式**（[#61](https://github.com/vahiru/gaokun-android/pull/61)、[#114](https://github.com/vahiru/gaokun-android/pull/114)）：读取每台机器出厂写入固件的校准数据，以3D LUT装入显示后处理模块，修正DPU写入颜色矩阵时的两处错误，开启Display P3与10-bit输出，并在“设置 → 显示 → 颜色”中提供**鲜艳**（默认）与**标准**两档。
* **HDR视频播放**（[#62](https://github.com/vahiru/gaokun-android/pull/62)、[#65](https://github.com/vahiru/gaokun-android/pull/65)）：播放HDR视频时抬高背光并压暗界面白电平，使高光能够高于普通界面白；内置屏声明支持HDR10与HLG，HEVC解码器列出Main10 HDR10。由于面板无分区背光，背光抬高时暗部亮度也会随之上升。
* **毛玻璃与横向开机**（[#57](https://github.com/vahiru/gaokun-android/pull/57)、[#82](https://github.com/vahiru/gaokun-android/pull/82)）：补回crDroid 17移除的锁屏、通知栏与控制中心背景模糊；开机动画与开机后的初始方向改为横向。
* **10-bit硬件解码与播放修复**（[#59](https://github.com/vahiru/gaokun-android/pull/59)、[#60](https://github.com/vahiru/gaokun-android/pull/60)）：支持HEVC Main10与VP9 Profile 2的硬件解码与上屏显示；修复mpv类播放器（如PiliPlus）开播即退回软件解码、字节缓冲模式下解码服务崩溃、固件看门狗复位后硬件解码失效直至重启，以及1080p画面底部多出8行的问题。
* **硬件视频编码**（[#116](https://github.com/vahiru/gaokun-android/pull/116)、[#118](https://github.com/vahiru/gaokun-android/pull/118)、[#106](https://github.com/vahiru/gaokun-android/issues/106)）：相机录像、`screenrecord`与应用内视频编码启用`iris` H.264 / HEVC硬件编码器，并修复640×480、800×480等高度非16对齐分辨率首帧报错的问题。息屏与单路限制见下文*已知问题*。

## 音频

* **麦克风阵列、通话回声消除与NPU降噪**（[#70](https://github.com/vahiru/gaokun-android/pull/70)、[#84](https://github.com/vahiru/gaokun-android/pull/84)）：修复内置麦克风录音的脉冲噪声（DMIC时钟由4.8 MHz改为3.2 MHz）、开头咔哒声和低频缺失，并提高采集增益；录音切换为四路同步采集，由顶部三颗麦克风做固定波束成形输出双声道；语音和视频通话先经WebRTC AEC3消除扬声器回声（解决此前外放通话对方听到回声的问题），再由CDSP NPU运行DeepFilterNet3降噪。通话默认开启降噪，普通录音和相机录像默认关闭，可在“设置 → 提示音和振动 → 麦克风降噪”中分场景开关。
* **降低游戏音频延迟**（[#110](https://github.com/vahiru/gaokun-android/pull/110)、[#117](https://github.com/vahiru/gaokun-android/pull/117)）：扬声器ALSA播放缓冲从4 × 480帧（40 ms）减至3 × 240帧（15 ms），HAL播放块缩至5 ms，合计降低游戏音频延迟约32 ms。
* **有线耳机听感修复**（[#119](https://github.com/vahiru/gaokun-android/pull/119)）：关闭耳机通路的RX宏压扩器，耳放改为AB类模式，低电平信号不再被整体抬高约20 dB。

## GPU

* **修复可触发整机重启的内核空指针问题**（[#112](https://github.com/vahiru/gaokun-android/pull/112)）：7.2.9的`drm/msm`驱动会在GPU地址空间建立之前访问它，任何能打开渲染节点的程序都可能触发空指针崩溃。已回移Linux 7.3-rc1中的5个上游修正。
* **启用Adreno 690抢占**（[#113](https://github.com/vahiru/gaokun-android/pull/113)）：SurfaceFlinger的界面合成可以插入正在执行的游戏渲染任务，GPU满载时的整屏掉帧大幅减少（《世界计划》实测SurfaceFlinger每秒错过刷新从3.57次降至0.2–0.45次）。

## 已知问题

* **息屏状态下的硬件视频编码**：屏幕关闭后，若后台仍在录像、导出或压缩视频，视频硬件可能挂起，导致成片缺帧或提前结束，此后录像也可能持续失败直至重启；编码期间请保持屏幕点亮。同一时刻仅支持一路硬件编码，120 Hz下的系统录屏仍使用软件编码。
* **指纹限制**：指纹HAL申报为便利级（Class 1），银行与支付类应用的指纹支付无法使用；FocalTech FTE7001传感器的像素间距比例还未用真实手指测量，配备该传感器的机器上识别率未经实测。
* **深度待机的注意事项**：每次进出深度待机会对NVMe SSD断电一次（长期寿命影响暂无数据，非群联主控SSD上的多轮睡眠测试仍在安排中）；若内部USB控制器在待机后偶发失联，整机仍能正常睡眠（[#73](https://github.com/vahiru/gaokun-android/pull/73)），但键盘盖与手写笔需重启后恢复。

## 已知限制

完整列表与应对建议见
**[docs/known-limitations.zh-CN.md](https://github.com/vahiru/gaokun-android/blob/v1.0.0-rc.4/docs/known-limitations.zh-CN.md)**
（[English](https://github.com/vahiru/gaokun-android/blob/v1.0.0-rc.4/docs/known-limitations.md)）。简要摘要：

* **安全模型**：系统由Android公开测试密钥签名；`/data`**未加密**；内核内置root（KernelSU / ReSukiSU）；启动链未锁定。
* **镜像包含的专有组件**：华为固件与设备校准数据、华为Histen音效引擎、高通QNN运行库（用于麦克风降噪）以及Google应用（MindTheGapps）。
* **不支持或不完整的功能**：设置中的“清除所有数据”（未经实测，请用图形安装器的“重新安装Android”）；指纹支付（仅支持锁屏解锁）；一代M-Pencil；GPS与定位；DRM流媒体视频（无Widevine）；通话时使用蓝牙耳机麦克风；不使用FCM的应用在待机期间的实时推送；Google认证（需手动登记一次，Play Integrity无法通过）。
