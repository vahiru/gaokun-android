## 相机

* **切换至硬件ISP**（[#120](https://github.com/vahiru/gaokun-android/pull/120)；最初像素通路实现来自**@dezige131**）：由高通IFE硬件接管图像处理，后摄合并模式最高支持60 fps（后摄全尺寸与前摄为30 fps），取景时CPU占用大幅下降，按下快门时预览不再停顿；支持数码变焦、相位对焦与对比度精调、曝光补偿、AE/AWB锁定、手动曝光与手动对焦、白平衡预设、50/60 Hz防频闪、拍照降噪及带缩略图的EXIF信息。
* **自动曝光与色彩改进**（[#86](https://github.com/vahiru/gaokun-android/pull/86)、[#87](https://github.com/vahiru/gaokun-android/pull/87)、[#126](https://github.com/vahiru/gaokun-android/pull/126)）：背景有灯具、窗户等小面积强光时不再将整幅画面压暗；消除前摄暗光下画面周期性忽明忽暗的现象；加入前后摄色彩校正与贝叶斯白平衡。
* **方向与兼容性修复**（[#83](https://github.com/vahiru/gaokun-android/pull/83)、[#87](https://github.com/vahiru/gaokun-android/pull/87)、[#115](https://github.com/vahiru/gaokun-android/pull/115)；[#42](https://github.com/vahiru/gaokun-android/issues/42)，感谢**@mashen11**）：修复前后摄画面旋转90°、Aperture切入录像模式崩溃及QQ等Camera1应用无法打开相机的问题；Camera1应用的录像规格提升至1080p。

* **待机FCM推送唤醒**（[#81](https://github.com/vahiru/gaokun-android/pull/81)、[#88](https://github.com/vahiru/gaokun-android/pull/88)、[#89](https://github.com/vahiru/gaokun-android/pull/89)）：息屏待机期间收到Google推送（FCM）数据包时可唤醒系统及时送达通知；修复进入休眠时偶发丢失Wi-Fi连接的问题。
* **稳定性修复**（[#73](https://github.com/vahiru/gaokun-android/pull/73)、[#76](https://github.com/vahiru/gaokun-android/pull/76)、[#77](https://github.com/vahiru/gaokun-android/pull/77)、[#79](https://github.com/vahiru/gaokun-android/pull/79)）：改进Wi-Fi固件崩溃恢复，消除关闭Wi-Fi后发生固件崩溃导致每次唤醒多停留一分钟的问题；缩短NTP校时超时；修复待机约6小时后传感器服务失效的问题；内部USB控制器异常时不再阻断系统休眠。

## 显示与视频

* **面板自动识别与出厂色彩校准**（[#58](https://github.com/vahiru/gaokun-android/pull/58)、[#61](https://github.com/vahiru/gaokun-android/pull/61)、[#114](https://github.com/vahiru/gaokun-android/pull/114)）：单一镜像自动适配BOE与CSOT面板；加载每台机器出厂写入固件的3D LUT色彩校准数据，开启Display P3广色域与10-bit显示，在“设置 → 显示 → 颜色”中提供**鲜艳**（默认）与**标准**两种模式。
* **HDR视频提亮**（[#62](https://github.com/vahiru/gaokun-android/pull/62)、[#65](https://github.com/vahiru/gaokun-android/pull/65)）：支持HDR10与HLG视频播放自动提亮以呈现高光细节（因LCD面板无分区背光，背光抬高时暗部亮度也会相应上升）。
* **10-bit硬件解码与播放修复**（[#59](https://github.com/vahiru/gaokun-android/pull/59)、[#60](https://github.com/vahiru/gaokun-android/pull/60)）：支持HEVC Main10与VP9 Profile 2硬件解码上屏；修复PiliPlus等mpv类播放器退回软件解码、解码服务崩溃、解码硬件复位后无法恢复硬解，以及1080p视频底部多出8行像素的问题。
* **硬件视频编码**（[#116](https://github.com/vahiru/gaokun-android/pull/116)、[#118](https://github.com/vahiru/gaokun-android/pull/118)、[#106](https://github.com/vahiru/gaokun-android/issues/106)）：相机录像、`screenrecord`与应用内视频处理启用H.264 / HEVC硬件编码。*注：同一时刻仅支持一路硬件编码（120 Hz下的系统录屏仍使用软件编码）；屏幕关闭后后台继续录像、导出或压缩视频可能导致编码硬件挂起，处理视频期间请保持屏幕点亮。*
* **界面模糊与横向开机**（[#57](https://github.com/vahiru/gaokun-android/pull/57)、[#82](https://github.com/vahiru/gaokun-android/pull/82)）：恢复锁屏、通知栏与控制中心的背景模糊；开机动画与开机后的初始方向改为横向。

## 触摸、手写笔与键盘盖

* **手写笔精度与设置页**（[#67](https://github.com/vahiru/gaokun-android/pull/67)、[#74](https://github.com/vahiru/gaokun-android/pull/74)、[#75](https://github.com/vahiru/gaokun-android/pull/75)、[#78](https://github.com/vahiru/gaokun-android/pull/78)；部分CSOT校准代码来自**@Rivarise**的[#63](https://github.com/vahiru/gaokun-android/pull/63)）：减轻斜线抖动与折角，修正CSOT屏左右边缘笔迹向内偏移的问题；新增“设置 → 已连接的设备 → 手写笔设置”，提供四档笔迹平滑调节与双击笔身功能设置（切换橡皮擦、侧键单击或关闭）。

## 侧边指纹

* **支持录入与锁屏解锁**（[#92](https://github.com/vahiru/gaokun-android/pull/92)、[#123](https://github.com/vahiru/gaokun-android/pull/123)）：可在设置中录入指纹并用于锁屏解锁，兼容Goodix与FocalTech传感器，连续失败触发临时锁定后可正常冷却恢复。录入不再有90秒时限，按完所需次数即可录成。*注：安全等级为便利级，不支持银行及支付类应用的指纹支付；配备FocalTech传感器的机型尚未完成识别参数校准，录入时较多按压会因图像质量被拒，录入一个手指往往要按三四十次（在一台FocalTech机器上实测，录入后锁屏解锁5次全部成功）；若识别率偏低请先使用密码解锁并反馈。*

## GPU与系统

* **GPU稳定性与抢占**（[#112](https://github.com/vahiru/gaokun-android/pull/112)、[#113](https://github.com/vahiru/gaokun-android/pull/113)）：修复一处可由普通应用触发整机重启的GPU驱动空指针崩溃；开启Adreno 690抢占，大幅减少高负载游戏场景下的系统界面合成掉帧。
* **ReSukiSU管理器可以授权root**：内核内置的ReSukiSU升级到`v4.2.0-rc3`，与目前最新发布的管理器接口版本一致。此前安装最新管理器只会提示“需要更新内核”，无法为应用和Shell授予root。
* **内核版本伪装**（[#69](https://github.com/vahiru/gaokun-android/pull/69)）：改为仅对普通应用返回伪装版本号，系统设置与`uname -r`显示真实Linux版本；可在“设置 → 系统 → 内核版本伪装”中关闭或修改（默认开启）。
* **启动与外设修复**（[#66](https://github.com/vahiru/gaokun-android/pull/66)、[#53](https://github.com/vahiru/gaokun-android/pull/53)，感谢**@Rivarise**；[#96](https://github.com/vahiru/gaokun-android/pull/96)、[#97](https://github.com/vahiru/gaokun-android/pull/97)、[#98](https://github.com/vahiru/gaokun-android/pull/98)、[#99](https://github.com/vahiru/gaokun-android/pull/99)、[#121](https://github.com/vahiru/gaokun-android/pull/121)、[#125](https://github.com/vahiru/gaokun-android/pull/125)）：纯Android模式的开机菜单等待时间缩短至5秒；修复远离电源键的USB-C口在重新协商后USB 2.0失灵的问题；修复电池温度恒为0 °C的问题；系统与USB / adb序列号改为上报整机真实序列号（不再固定为`gaokun3`）；开启内核BTF、`userfaultfd`及混合ISO格式的Live安装器所需的`ISO9660`支持；独立发布免U盘双系统图形安装工具[Windows安装器0.1.0](https://github.com/vahiru/gaokun-android/releases/tag/windows-installer-v0.1.0)。
