## 升级与安装须知

* **系统更新（OTA）**：`v1.0.0-rc.3`与`v1.0.0-rc.4`用户可在“设置 → 系统 → 系统更新”中直接升级。升级前请备份重要数据：新版本首次成功启动后不再支持保留数据退回旧版本。仍在Android 16上的`v0.7.1-alpha`、`v1.0.0-rc.1`与`v1.0.0-rc.2`用户不会收到本次系统更新（系统更新不会将Android 16直接升至17），请使用安装器重新安装（会清除数据）。
* **屏幕方向与默认显示大小变化**：本版本起系统自然方向改为横屏，竖屏应用在横屏时默认居中显示（可在“设置 → 应用 → 宽高比”中按应用设为全屏；此前如手动执行过`wm set-ignore-orientation-request`，升级后需运行`adb shell wm set-ignore-orientation-request reset`恢复）；默认屏幕密度由240调整为280，未自定义显示大小的设备界面整体放大约17%，可在“设置 → 显示 → 显示大小”或开发者选项的“最小宽度”中调整（原240对应`1067` dp）。
* **全新安装**：可在Windows中直接运行[Windows安装器0.2.1](https://github.com/vahiru/gaokun-android/releases/tag/windows-installer-v0.2.1)安装双系统或制作安装介质，或直接使用[Live安装器0.2.0（v1.0.0-rc.5）](https://github.com/vahiru/gaokun-android/releases/tag/live-installer-v0.2.0-for-v1.0.0-rc.5)；详细步骤见[安装说明](https://github.com/vahiru/gaokun-android/blob/v1.0.0-rc.5/docs/INSTALL.zh-CN.md)，安装前请阅读[已知限制](https://github.com/vahiru/gaokun-android/blob/v1.0.0-rc.5/docs/known-limitations.zh-CN.md)与[常见问题](https://github.com/vahiru/gaokun-android/blob/v1.0.0-rc.5/docs/FAQ.zh-CN.md)。

## 更新内容

### 显示与窗口管理

* **自然方向改为横屏与竖屏应用适配**（[#158](https://github.com/vahiru/gaokun-android/pull/158)、[#162](https://github.com/vahiru/gaokun-android/pull/162)）：屏幕自然方向调整为横屏（接键盘横放即为默认方向），触摸、手写笔、加速度计、相机与侧边指纹提示位置同步更新，已有旋转锁定设置会在升级后自动迁移；同时更正面板物理尺寸，使应用读取到实际的约245 dpi。只支持竖屏的应用在横屏时居中显示，不再强制将整块屏幕转为竖屏，需要铺满屏幕时可在“设置 → 应用 → 宽高比”中按应用选择“全屏”；只支持横屏的应用与全屏视频仍会自动转为横屏。
* **平行视界（实验性）**（[#159](https://github.com/vahiru/gaokun-android/pull/159)、[#162](https://github.com/vahiru/gaokun-android/pull/162)）：新增“设置 → 应用 → 平行视界（实验性）”，读取应用自带的分栏规则，在横屏时将页面左右分栏显示；拖动分隔条时实时显示两侧页面的截图；右侧页面请求横屏（如播放全屏视频）时自动展开为整屏。*注：默认全部关闭，列表仅显示自带分栏规则的应用；权限对话框可能被右侧页面遮挡一部分，微信主列表聊天与左侧页面全屏等仍有限制，详见[已知限制](https://github.com/vahiru/gaokun-android/blob/v1.0.0-rc.5/docs/known-limitations.zh-CN.md#应用页面左右分栏显示为实验性功能)。*
* **默认屏幕密度调整为280**（[#168](https://github.com/vahiru/gaokun-android/pull/168)）：默认屏幕密度由240提高至280（未调整过显示大小的设备界面整体放大约17%，已调整过的保留原有设置），更贴合平板的日常观看距离；如需调整界面缩放，可在“设置 → 显示 → 显示大小”或开发者选项的“最小宽度”中设置（原240对应`1067` dp）。

### 硬件视频编解码

* **HEVC Main 10 / HDR10硬件编码与最多3路并发**（[#188](https://github.com/vahiru/gaokun-android/pull/188)、[#190](https://github.com/vahiru/gaokun-android/pull/190)、[#194](https://github.com/vahiru/gaokun-android/pull/194)、[#202](https://github.com/vahiru/gaokun-android/pull/202)）：硬件视频编码新增支持HEVC Main 10与HDR10编码；同时硬件编码并发会话数由1路提升至最多3路（相机录像与系统录屏均可直接使用硬件编码）；修正640×480等尺寸录屏的色度错位，并去除IDR关键帧之间多余的周期性I帧。*注：仅HEVC提供10-bit编码，HLG与P3-D65色彩描述仅写入容器，不支持`RGBA_1010102`输入；固件出错重载时所有进行中的编解码会话会一起报错，休眠唤醒后偶发一次编码无输出的问题仍待排查。*
* **息屏编码稳定、时钟限制与解码能力修复**（[#141](https://github.com/vahiru/gaokun-android/pull/141)、[#189](https://github.com/vahiru/gaokun-android/pull/189)、[#191](https://github.com/vahiru/gaokun-android/pull/191)、[#192](https://github.com/vahiru/gaokun-android/pull/192)、[#193](https://github.com/vahiru/gaokun-android/pull/193)、[#195](https://github.com/vahiru/gaokun-android/pull/195)、[#196](https://github.com/vahiru/gaokun-android/pull/196)、[#197](https://github.com/vahiru/gaokun-android/pull/197)、[#198](https://github.com/vahiru/gaokun-android/pull/198)、[#199](https://github.com/vahiru/gaokun-android/pull/199)、[#200](https://github.com/vahiru/gaokun-android/pull/200)；[#134](https://github.com/vahiru/gaokun-android/issues/134)）：修复屏幕关闭而系统未休眠时后台录像、导出或压缩视频导致编码硬件挂起的问题；将视频编解码硬件核心时钟限制在444 MHz以消除编码偶发丢帧；限制解码器IOVA范围并缩小输入缓冲区，避免多路视频同时解码时整机复位；按实测重新申报解码器帧率与级别能力（支持VP9 5.1/5.2及H.264 1440p@120等），修正解码器DCI-P3三原色映射、flush后位深切换、强停或退出时的驱动报错、轮询空转及固件错误恢复；放行Codec2 HAL崩溃转储系统调用，执行`adb bugreport`时不再结束编解码服务。

### 相机与手电筒

* **支持前后摄全部四种模组与S5K3L6相位对焦**（[#156](https://github.com/vahiru/gaokun-android/pull/156)、[#184](https://github.com/vahiru/gaokun-android/pull/184)、[#185](https://github.com/vahiru/gaokun-android/pull/185)、[#186](https://github.com/vahiru/gaokun-android/pull/186)；[#139](https://github.com/vahiru/gaokun-android/issues/139)）：新增板级相机模组探测器，同一镜像自动识别并启用前摄海力士HI846 / 三星S5K4H7以及后摄豪威OV13B10 / 三星S5K3L6全部四种模组，并为S5K3L6后摄支持全尺寸相位对焦。*注：S5K3L6调校参数取自Windows驱动，拍摄均匀白面时边缘可能略偏绿；其相位对焦步进系数与改由探测器选择后的S5K4H7机型仍待更多实机验证。*
* **手电筒亮度档位**（[#148](https://github.com/vahiru/gaokun-android/pull/148)；[#108](https://github.com/vahiru/gaokun-android/issues/108)）：后置手电筒支持20档亮度调节（10–200 mA），可在快捷设置的手电筒磁贴中拖动滑块调节。

### 侧边指纹

* **支持应用内指纹验证与绑定指纹的密钥**（[#133](https://github.com/vahiru/gaokun-android/pull/133)、[#180](https://github.com/vahiru/gaokun-android/pull/180)）：指纹服务升级为报告`STRONG`并签发认证令牌，除锁屏解锁外，现已支持在应用中通过指纹验证身份（例如登录账号、解锁密码管理器）以及使用绑定指纹的密钥库密钥；同时修复配备FocalTech（`FTE7001`）传感器的机器上录入无响应与出错后无法重试的问题。*注：微信支付、支付宝等依赖设备厂商TEE预置密钥的指纹支付仍无法使用，部分银行应用可能不接受软件密钥库；FocalTech传感器尚未完成像素间距校准，录入时可能需要按压较多次数。*

### 温控、性能与电源调度

* **板载热敏电阻温控、被动降温与性能模式**（[#160](https://github.com/vahiru/gaokun-android/pull/160)、[#161](https://github.com/vahiru/gaokun-android/pull/161)、[#171](https://github.com/vahiru/gaokun-android/pull/171)、[#177](https://github.com/vahiru/gaokun-android/pull/177)、[#179](https://github.com/vahiru/gaokun-android/pull/179)）：按Windows配置启用四路板载热敏电阻温控区，沿用Windows被动降温公式加深或减轻降频，并向Android框架上报外壳温控等级；在“设置 → 电池”中新增**性能模式**开关，开启后可提高长时间高负载下的温度上限。机身过热时自动按`sys-therm2`–`4`中最高的温控等级限制最高屏幕亮度（中度过热约为最高亮度的78%，重度及以上约为56%，不影响HDR内容）。
* **全新Power HAL与分电源状态调度**（[#163](https://github.com/vahiru/gaokun-android/pull/163)、[#165](https://github.com/vahiru/gaokun-android/pull/165)、[#172](https://github.com/vahiru/gaokun-android/pull/172)、[#173](https://github.com/vahiru/gaokun-android/pull/173)）：切换至`lineage-libperfmgr`作为Power HAL，在触摸、启动应用与游戏加载时按需提升性能，支持ADPF按帧耗时动态调度与省电模式限频，不再由实时线程将整簇CPU拉满；修复系统服务调整应用cgroup分组的权限。按Windows电源策略区分接电源与用电池：接电源时保持更高的CPU频率下限并解除后台与非焦点窗口限频，用电池时限制后台与非焦点自由窗口频率以控制功耗。

### 触摸屏

* **屏幕无触摸时降低触摸屏功耗**（[#219](https://github.com/vahiru/gaokun-android/pull/219)）：最后一次触摸约3秒后，触摸屏转入低功耗扫描，触摸屏幕或使用手写笔时自动恢复正常扫描。
* **点击不再误判为拖动**（[#212](https://github.com/vahiru/gaokun-android/pull/212)）：抬手瞬间的坐标跳动不再上报，游戏与列表中的点击不易被识别为拖动或滑动。
* **丢弃不完整的触摸数据并自动恢复**（[#211](https://github.com/vahiru/gaokun-android/pull/211)）：校验失败的触摸数据帧不再参与计算；触摸芯片连续出错或固件自行重启时，会自动重新初始化。

### 手写笔

* **吸附即可配对**（[#209](https://github.com/vahiru/gaokun-android/pull/209)）：尚未与平板配对的M-Pencil（例如连接过其他设备的笔）吸附到平板顶部的充电区域即可完成配对，不再只能悬停而无法书写。*注：三代笔与在两支笔之间切换尚未实测。*
* **未配对提示与配对完成通知**（[#210](https://github.com/vahiru/gaokun-android/pull/210)）：使用未配对的M-Pencil书写时，系统提示将笔吸附到平板顶部的充电区域完成配对；配对完成后发出“已连接到M-Pencil 2”或“已连接到M-Pencil 3”通知，点按即可打开“设置 → 已连接的设备 → 手写笔设置”。
* **连接过其他设备的笔不再出现锯齿笔迹**（[#213](https://github.com/vahiru/gaokun-android/pull/213)）：连接过其他华为设备的M-Pencil回到本机后，书写时不再出现锯齿状的折线。*注：三代笔与CSOT屏尚未实测。*
* **笔尖松动提示**（[#214](https://github.com/vahiru/gaokun-android/pull/214)）：M-Pencil的笔尖松动时，书写过程中会发出提示，提醒检查并拧紧笔尖。*注：三代笔与CSOT屏上的笔尖松动尚未实测。*
* **手写笔设置显示已连接的笔并可断开连接**（[#215](https://github.com/vahiru/gaokun-android/pull/215)）：“设置 → 已连接的设备 → 手写笔设置”在标题下显示已连接的M-Pencil，新增“断开连接”按钮，断开后将笔吸附到平板顶部的充电区域即可重新连接。笔迹平滑的说明移至滑条下方，拖动滑条时在上方显示档位名称。*注：三代笔尚未实测。*
* **双击笔身默认不再切换橡皮擦**（[#216](https://github.com/vahiru/gaokun-android/pull/216)）：Android不提示当前使用的是笔还是橡皮擦，不支持橡皮擦的应用在切换后会写不出笔迹。现在双击笔身默认不响应；如需使用，可在“设置 → 已连接的设备 → 手写笔设置 → 双击笔身功能”中选择“切换橡皮擦”或“侧键单击”。此前已选择过的设置保持不变。

### 蓝牙、音频与设置整理

* **支持蓝牙耳机通话**（[#174](https://github.com/vahiru/gaokun-android/pull/174)；[#107](https://github.com/vahiru/gaokun-android/issues/107)）：启用HFP软件数据通路，连接蓝牙耳机后可在通话中使用耳机播放与麦克风收音。*注：已在mSBC宽带耳机上验证双向收发通路；微信语音、网络会议等实际通话应用、仅支持CVSD的窄带耳机，以及通话中由耳机主动将声音切回平板的场景尚未实测。*
* **整理设备专属设置条目与通知**（[#176](https://github.com/vahiru/gaokun-android/pull/176)、[#178](https://github.com/vahiru/gaokun-android/pull/178)）：“磁吸键盘”开关移入“设置 → 已连接的设备”；原“触摸手感”改为“设置 → 显示 → 防误触模式”开关及“防误触”快捷设置磁贴；“扬声器音效”（改为弹窗单选）与“麦克风降噪”归入“设置 → 提示音和振动”中的“高级”分组；应用抽屉不再显示独立入口图标；精简并统一USB-C与启动异常通知。

### 游戏与图形

* **按应用开启GPU驱动兼容与虚幻引擎游戏修复**（[#151](https://github.com/vahiru/gaokun-android/pull/151)、[#164](https://github.com/vahiru/gaokun-android/pull/164)；[#33](https://github.com/vahiru/gaokun-android/issues/33)）：新增“设置 → 系统 → GPU驱动兼容”，可为指定应用在`GL_VERSION`中报告高通驱动版本，解决《无限暖暖》等只附带Vulkan着色器的虚幻引擎游戏启动报错退出的问题（*请勿为浏览器开启，否则部分WebGL网页将无法正常显示*）；回移Mesa上游保留无穷大与有符号零的两项修正，修复《无限暖暖》进入大世界后实时3D画面全黑的问题。*注：以上两项改动尚未在游戏内完成完整实测。*
* **微信页面卡死、《原神》水面与未定义的着色器值**（[#155](https://github.com/vahiru/gaokun-android/pull/155)、[#169](https://github.com/vahiru/gaokun-android/pull/169)、[#207](https://github.com/vahiru/gaokun-android/pull/207)；[#131](https://github.com/vahiru/gaokun-android/issues/131)）：规避微信Flutter引擎重复等待信号量导致公众号、服务号、游戏中心等页面无法显示及离开时卡死的问题；修正《原神》在分块渲染下未写回深度缓冲导致的水面在部分帧中消失及灌木后方物体遮挡错乱（*游戏内实测效果待确认*）；修正Turnip在部分着色器中让未初始化的变量读到残留值的问题，修复部分应用因此出现的黑块或渲染异常。
* **GPU稳定性、带宽与手柄支持**（[#142](https://github.com/vahiru/gaokun-android/pull/142)、[#152](https://github.com/vahiru/gaokun-android/pull/152)、[#167](https://github.com/vahiru/gaokun-android/pull/167)；[#101](https://github.com/vahiru/gaokun-android/issues/101)，GPU内核修正来自**Xilin Wu**）：回移GPU SMMU上下文中断与DDR峰值带宽投票的上游修正，移除原有的临时轮询服务`smmustall`，高负载下DDR带宽可随GPU频率提升；内核开启游戏手柄驱动，支持有线Xbox手柄等外设。

### 内存、网络与系统修复

* **内存管理与流畅度改进**（[#149](https://github.com/vahiru/gaokun-android/pull/149)、[#150](https://github.com/vahiru/gaokun-android/pull/150)、[#166](https://github.com/vahiru/gaokun-android/pull/166)、[#167](https://github.com/vahiru/gaokun-android/pull/167)）：由`mmd`启用zram交换空间（容量为物理内存的一半，lz4压缩）；取消开机20分钟后自动压缩全部系统进程的行为，消除游戏过程中突然出现约1秒剧烈掉帧和扬声器爆音的问题；与Android GKI对齐透明大页（改为`madvise`）、MGLRU页面回收、uclamp桶数及调度诊断配置。
* **Wi-Fi、USB-C、锁屏充电信息与底层修复**（[#132](https://github.com/vahiru/gaokun-android/pull/132)、[#135](https://github.com/vahiru/gaokun-android/pull/135)、[#143](https://github.com/vahiru/gaokun-android/pull/143)、[#146](https://github.com/vahiru/gaokun-android/pull/146)、[#153](https://github.com/vahiru/gaokun-android/pull/153)、[#154](https://github.com/vahiru/gaokun-android/pull/154)、[#175](https://github.com/vahiru/gaokun-android/pull/175)、[#181](https://github.com/vahiru/gaokun-android/pull/181)、[#183](https://github.com/vahiru/gaokun-android/pull/183)；[#102](https://github.com/vahiru/gaokun-android/issues/102)，PCIe缓存一致性补丁来自**Xilin Wu**）：Wi-Fi改用`HW_GK3`板级校准数据放开2.4 GHz第12、13信道，支持框架下发国家码至WCN6855固件并内置无线监管数据库（`regulatory.db`），并修复开机后才启动的AP无法被搜索到的问题；USB角色与连接电脑时的防休眠锁改由USB端口HAL接管，USB-C控制器（UCSI）开机初始化超时后自动重试最多5次（触发重试时端口在开机后约晚15秒可用）并在最终失败后确认EC重复发送的USB事件以避免阻断休眠；修复锁屏无法显示充电电流、功率、电压、温度及“正在快速充电”状态的问题；强制SC8280XP的PCIe事务经过缓存一致性处理；减少显示合成日志中重复输出的多余光标平面警告。
* **WLAN直连**（[#208](https://github.com/vahiru/gaokun-android/pull/208)）：启用WLAN直连，可在“设置 → 网络和互联网 → 互联网 → 网络偏好设置 → WLAN直连”中搜索并连接手机等支持WLAN直连的设备，连接期间平板的Wi-Fi连接不会中断。*注：开启热点时无法使用WLAN直连；在部分国家和地区，由平板创建的群组无法使用5 GHz频段，详见[已知限制](https://github.com/vahiru/gaokun-android/blob/v1.0.0-rc.5/docs/known-limitations.zh-CN.md#wlan直连的限制)。*
