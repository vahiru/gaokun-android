华为 **MateBook E Go**（骁龙 8cx Gen 3 / SC8280XP）上的 **Android 17（crDroid 13）**，跑在**主线 Linux 内核**上，Adreno 690 有硬件 Vulkan。

**1.0 的第三个候选版，首先是一次安全修复。** 之前的所有版本都会在每次内核崩溃时把日志写进主板固件存储（NVRAM），而且从不清理，
存储写满后 **U 盘和官方恢复镜像都无法启动**（[#56](https://github.com/vahiru/gaokun-android/issues/56)）。这一版不再写入。
同时这一版**从 Android 16 升到 Android 17**，并带上了扬声器、自动亮度、触摸和手写笔的改进。

**交流：** [Telegram](https://t.me/gaokunAndroid) · QQ 群 **920133252**

> ### ⚠️ 必读：安全修复只停止新的写入，已经写进去的记录要你自己清一次
> 更新之后请按 [#56](https://github.com/vahiru/gaokun-android/issues/56) 或[常见问题](https://github.com/vahiru/gaokun-android/blob/v1.0.0-rc.3/docs/FAQ.zh-CN.md#开机与启动菜单)检查一次。
> 出现过「U 盘不出现在启动菜单里」的，**主板没有坏，不需要换主板**，清掉记录就好。
>
> ### ⚠️ 这是一次大版本升级（Android 16 → 17）
> **rc.2、rc.1 和 v0.7.1-alpha 的用户都会在「系统更新」里收到这一版。** 更新前**请先备份**：
> Android 17 第一次开机时会升级 `/data` 里的数据，而这台机器上 `/data` 没有回滚点。如果更新后起不来，开机菜单里还能选上一个 Android 启动项
> （需要键盘），但旧系统在被新系统改过的数据上不一定能正常开机，可能要清除数据或用图形安装器重装。
> 「系统更新」里这一版会显示成 Android 16 的普通更新，这是为了让旧版本的更新程序放行，装上以后就是 Android 17。
>
> 全新安装会**清空内置硬盘**（图形安装器的双系统模式除外）。你要能自己救回一台开不了机的机器。不提供任何保证。必须关闭安全启动。

## 这个候选版是怎么测的

2026-10-30，构建 `1793322048`（incremental `20261030010048`）通过 OTA 安装到开发机备用槽，使用一次性启动进入，SELinux 为 Enforcing。A 档验收 **46 PASS / 0 FAIL / 2 WARN / 0 SKIP**，包括前后相机、麦克风、GPU 与硬件解码。两项提示为开机不足十分钟，以及此前 A17 已有的 InputReader `country` / gpuservice BPF 属性查询拒绝。

真机确认 `efi_pstore.pstore_disable=Y`，pstore backend 为 `(null)`，没有注册 EFI 写入后端。验收时暂时关闭了开发机持久化的 TCP adb。此次实际升级路径为 A17 → A17；**没有重新演练 A16 → A17 的 OTA**。

硬解回归 **15/15 PASS**，覆盖 AVC / HEVC / VP9 的 seek、EOS、stop、drain 和分辨率切换，iris 错误为 0；之后前后相机冒烟复测均通过。

## 安全修复：固件存储被崩溃记录占满

* 内核不再把崩溃日志写进固件变量（启动参数 `efi_pstore.pstore_disable=1`，内核配置也默认关闭）。代价是内核崩溃后不再留下记录，
  反馈死机问题时请尽量描述当时在做什么。
* 已经写进去的记录不会自动删除，按 #56 清一次。

## Android 17

* 系统从 crDroid 12（Android 16）升到 **crDroid 13（Android 17）**，安全补丁 2026-10-01。
* 图形驱动（Mesa / Turnip）随之换到 26.1。HEVC 硬件解码在 Android 17 上有一处回归，已经修好。

## 扬声器

* **修好了动态范围被严重压缩、大音量时破音的问题**（功放端口映射、动态 DRE、总线冲突）。
* **扬声器增强**放进了音频 HAL，扬声器播放的所有声音（包括游戏）都会经过处理。「设置」里可选**低音增强**（默认）或**华为 Histen**。

## 显示

* **自动亮度能用了**：环境光传感器有了驱动支持，默认开启。

## 触摸与手写笔

* 修复点击偶尔丢失、从屏幕边缘开始的触摸被整笔丢掉的问题；按下提前一帧上报，滑动更稳，不再抖动或拖尾。
* 音游里快速连点时，点击不再被并进刚抬起的那根手指。
* **手写笔**的坐标加了平滑并以亚像素精度上报，放大后笔迹不再锯齿。
