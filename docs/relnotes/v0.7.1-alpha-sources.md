# v0.7.1-alpha — kernel corresponding source

The kernel in the v0.7.1-alpha `boot.img` is GPL-2.0. It is built outside the
Android tree from four layers; this page pins each of them. Starting with the
next release, `scripts/release.sh` generates this list automatically and
attaches it to the release as `kernel-source.txt`, together with the `.config`
and the base-layer patches.

## Rebuilding

```sh
git clone --branch v7.2-rc2 https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git linux
cd linux
# layer 2: git am the linux-gaokun-buildbot patches (see section 2)
git -C <gaokun-android> checkout v0.7.1-alpha
bash <gaokun-android>/scripts/kernel-apply-patches.sh .
bash <gaokun-android>/scripts/kernel-setup-resukisu.sh .
mkdir -p ../kout && cp <gaokun-android>/docs/relnotes/v0.7.1-alpha-config.txt ../kout/.config
make ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- O=../kout olddefconfig vmlinuz.efi dtbs
```

Where the outputs go: [`device/huawei/gaokun3/prebuilt-boot/README.md`](../../device/huawei/gaokun3/prebuilt-boot/README.md).
