# 安装

[**English → INSTALL.md**](INSTALL.md) · [常见问题](FAQ.zh-CN.md) · [已知限制](known-limitations.zh-CN.md)

本文介绍如何在华为MateBook E Go上安装本系统，以及安装之后的系统更新、开机菜单和清除数据。

> ### ⚠️ 安装前须知
> 除保留现有系统（与Windows双系统）外，安装会清空内置硬盘，Windows和其中的文件将一并删除，且无法撤销。本项目不提供出厂系统的镜像，之后如需恢复Windows，请使用华为的恢复介质或Windows安装U盘重新安装。
>
> 请在开始前备份重要数据，并确保自己有能力处理机器无法开机的情况。

## 两种安装器

| | Windows安装器 | Live安装器 |
|---|---|---|
| 运行方式 | 在机器上的Windows中运行 | 从U盘或本机磁盘上的安装器分区启动，不依赖硬盘上已有的系统 |
| 支持的操作 | 安装到系统磁盘的未分配空间（与Windows双系统）；卸载Android；制作独立安装介质（Live安装器） | 保留现有系统（双系统）；清除整个磁盘；重新安装Android；删除分区；删除安装器分区 |
| 系统安装文件 | 联网下载最新版本，或使用已下载的本地文件 | 随安装介质附带，安装时不联网 |
| 适用情况 | 机器上有Windows，希望保留它 | 不保留Windows、重新安装Android或修复无法启动的系统 |

两种安装器只会安装到本机的内置硬盘。

## 准备工作

| 项目 | 要求 |
|---|---|
| 机型 | 华为MateBook E Go，2022款和2023款均可。安装器会检查型号，两款在系统信息中的型号都是GK-W7X |
| BIOS版本 | 不限 |
| Secure Boot | 必须关闭。系统内核未经签名，Secure Boot开启时无法启动 |
| 硬盘空间 | 保留Windows时，系统磁盘上需要至少20.2 GiB的连续未分配空间；先把Live安装器写入本机磁盘、再用它安装时，需要至少22.2 GiB |
| 安装介质 | 使用Live安装器时，需要一个4 GB或更大的U盘；也可以用Windows安装器把Live安装器写入本机磁盘，不需要U盘 |
| 电源 | 已连接电源适配器，或电量高于15% |
| 键盘盖 | 两种安装器都可以用手指操作，Live安装器带有屏幕键盘。开机菜单可以用音量键和电源键操作 |

不需要另一台电脑，也不需要adb或本仓库的代码。系统运行所需的固件已经包含在发布的镜像中。

另外请注意，本系统的用户数据分区没有加密，拿到机器的人可以读取其中的全部数据，详见[已知限制](known-limitations.zh-CN.md)。

### 如果要保留Windows

- **使用Windows安装器**：可直接先[下载](#下载)并运行Windows安装器，首页"安装环境检查"会逐项引导完成下方设置（包括查看阻碍压缩分区的文件，以及在关闭Secure Boot前先校验恢复密钥并暂停BitLocker保护），处理完毕后再进入固件设置关闭Secure Boot。
- **直接从U盘使用Live安装器**：开始安装前，请先在Windows中依次完成以下4步：

1. **关闭快速启动**：在"控制面板 → 电源选项 → 选择电源按钮的功能"中取消勾选"启用快速启动"。之后请用"关机"而不是"休眠"退出Windows。Windows处于休眠状态时，写入共用的EFI系统分区可能损坏其中的数据，安装器检测到时会拒绝操作。
2. **腾出空间**：在"磁盘管理"中压缩系统磁盘上的分区，腾出至少20.2 GiB的连续未分配空间（先把Live安装器写入本机磁盘、再用它安装时，至少22.2 GiB）。安装器不会调整现有分区的大小。分区无法压缩出足够的空间时，可在Windows安装器中查看阻碍压缩的文件并按提示处理。
3. **处理BitLocker**：如果启用了BitLocker或设备加密，请先确认能在<https://aka.ms/myrecoverykey>取得48位恢复密钥，并保存在手机等其他设备上备用。不经过Windows安装器暂停保护而直接关闭Secure Boot或修改引导文件时，Windows下次启动会要求输入该恢复密钥（系统磁盘开启BitLocker时的暂停与恢复尚未在本机上实测）。
4. **关闭Secure Boot**：设置 → 系统 → 恢复 → 高级启动 → 立即重新启动，然后选择疑难解答 → 高级选项 → UEFI固件设置，在固件设置中关闭Secure Boot。

## 下载

安装器与系统安装文件都在[Releases页面](https://github.com/vahiru/gaokun-android/releases)：

| 文件 | 用途 | 所在的发布 |
|---|---|---|
| `gaokun-android-windows-installer-<版本>-arm64.zip` | Windows安装器 | `windows-installer-v<版本>` |
| `gaokun3-live-<版本>-android-<系统版本>.iso` | Live安装器，附带该系统版本的安装文件（约1.5 GB），写入U盘后即可安装 | `live-installer-v<版本>-for-<系统版本>` |
| `gaokun3-live-<版本>-for-<系统版本>.iso` | Live安装器，不带系统安装文件（约180 MB），供Windows安装器制作安装介质使用，一般无需下载 | 同上 |
| `boot.img`、`super.img.zst`、`install-artifacts.sha256` | 系统安装文件 | 各系统版本的发布 |

每个系统版本发布后，都会随之发布一版附带该版本系统安装文件的Live安装器，请下载最新的一版。使用Windows安装器时，系统安装文件和Live安装器都由它下载，不需要手动下载。各文件的校验值见同一发布中的`.sha256`文件、`SHA256SUMS`和`install-artifacts.sha256`。

### 从镜像站下载系统安装文件

GitHub下载缓慢或无法连接时（例如在中国大陆），系统安装文件可以从镜像站下载。镜像站目前只提供系统安装文件，不提供安装器。使用Windows安装器时，可以把下载源切换为"R2镜像源"。手动下载的地址为：

```
https://ota.072172.xyz/install/<build>/<文件名>
```

`<build>`是该版本OTA包去掉`.zip`后的文件名，当前版本的文件名可以在<https://ota.072172.xyz/ota/gaokun3.json>的`filename`字段中查到。

## 使用Windows安装器

### 安装

1. 完整解压`gaokun-android-windows-installer-<版本>-arm64.zip`，运行其中的`gk3_windows.exe`，在提示时允许以管理员身份运行。请不要直接在压缩包预览窗口中运行。
2. 按"安装环境检查"的提示处理未满足的条件，全部通过后点击"下一步"。
3. 选择安装位置（系统磁盘上的一块未分配空间）、下载源，以及开机默认启动的系统。安装器会下载最新版本的系统；如需安装其他版本，可以选择"本地文件"，使用已下载的该版本安装文件。
4. 确认操作摘要无误后，按住确认按钮2秒开始安装。下载与写入约需数分钟，期间请不要合上键盘盖或按电源键。
5. 安装完成后重启，开机菜单中会出现Android和Windows。

安装器在所选的未分配空间中创建Android的分区，在EFI系统分区安装启动管理器（systemd-boot）并备份原有的默认引导文件（BOOTAA64.EFI）。C盘中的Windows和文件不受影响。

部分安全软件（例如火绒）可能在写入磁盘时拦截安装器的后端程序`gk3w.exe`。如果弹出拦截提示，请选择允许；中途拦截可能导致磁盘分区处于不完整状态。安装器的日志位于`%ProgramData%\gaokun3\logs`。

### 卸载

已经安装Android时，在"安装环境检查"页点击"管理"，再选择"卸载Android"。卸载会删除Android的全部分区和本机磁盘上的安装器分区，把EFI默认引导文件恢复为安装前的状态（通常为Windows启动管理器）。释放的空间保留为未分配状态，可以在"磁盘管理"中右键点击它之前的分区并选择"扩展卷"，将其合并回该分区。

### 制作安装介质

点击左侧菜单底部的"制作独立安装介质"，可以把Live安装器与系统安装文件写入：

- **U盘**：清空整个U盘后写入，制作完成后可以用于任意一台MateBook E Go。
- **本机磁盘**：在系统磁盘的未分配空间末尾创建约2 GiB的安装器分区（GK3LIVE），并在开机菜单中添加`gaokun3 installer`。还没有安装Android时，会在EFI系统分区安装启动管理器（systemd-boot）并备份原有默认引导文件（BOOTAA64.EFI），开机默认仍进入Windows。系统磁盘开启了BitLocker时（无论是否已安装Android），写入或单独删除安装器分区均需先校验恢复密钥。其他分区和其中的数据不受影响。

Live安装器只能从GitHub下载，或使用同一目录下的本地系统安装文件与Live安装器的ISO；选择"R2镜像源"时无法制作安装介质。

本机磁盘上已有安装器分区时，可以在"选择写入位置"一步中删除它（尚未安装Android时，删除后也会将EFI默认引导文件恢复为写入前的状态；单独删除安装器分区尚未在实机上验证）。安装Android后，Live安装器默认也会删除安装器分区。

## 使用Live安装器

### 准备安装介质

以下方式任选其一：

- **用Windows安装器制作**：见[制作安装介质](#制作安装介质)。
- **写入带系统安装文件的ISO**：把`gaokun3-live-<版本>-android-<系统版本>.iso`写入U盘。Rufus（选择"以DD镜像模式写入"）和balenaEtcher可以直接写入；在Linux上可以运行：

  ```sh
  sudo dd if=gaokun3-live-<版本>-android-<系统版本>.iso of=/dev/sdX bs=4M conv=fsync status=progress
  ```

- **把文件复制到U盘**：把U盘格式化为FAT32（Windows自带格式化仅支持32 GB及以下的U盘，更大容量请使用前两种方式），在Windows中双击打开带系统安装文件的ISO，把其中的全部文件复制到U盘。

### 启动Live安装器

- **从U盘启动**：插上U盘，开机时按`F12`进入固件启动菜单并选择它（见[常见问题](FAQ.zh-CN.md#怎么进入固件设置从u盘启动)）。
- **从本机磁盘启动**：开机时在开机菜单中选择`gaokun3 installer`。

Live安装器启动时通常会把安装文件全部读入内存，此后可以拔下U盘。

### 选择安装方式

| 安装方式 | 说明 |
|---|---|
| 保留现有系统（双系统） | 在最大的一块未分配空间中新建分区，不修改现有分区；在EFI系统分区安装启动管理器（systemd-boot）并备份原有引导文件，开机时显示启动菜单。需要先在Windows中腾出空间，见[如果要保留Windows](#如果要保留windows) |
| 清除整个磁盘 | 删除硬盘上的全部内容，按[分区布局](#分区布局)重新分区（此模式尚未在实机上验证）。从本机磁盘上的安装器分区启动时，清除期间保留该分区，安装完成后默认删除（见下文） |
| 重新安装Android | 硬盘上已有Android时可用。保留现有分区，重新写入系统，适合修复系统或更换版本。默认清除用户数据，可以在下一步选择"保留用户数据"；换到更旧的版本时，保留的数据可能导致无法开机 |
| 删除分区 | 删除硬盘上的分区，每次删除单独确认并立即执行 |
| 删除安装器分区 | 从本机磁盘上的安装器分区启动时可用（尚未在实机上验证）。删除该分区；还没有安装Android时，EFI系统分区一并恢复到写入安装器分区之前的状态 |

开始写入磁盘之前，安装器会显示一页风险提示，需要读到底、等待一段时间并勾选确认后才能继续；清除整个磁盘，或在装有Windows的硬盘上删除分区时，还需要输入`ERASE`。如果Windows分区启用了BitLocker，并且这次安装需要替换EFI分区上的默认引导文件，还需要先确认已经取得恢复密钥。

从本机磁盘上的安装器分区启动时，选项页中有"保留安装器分区"，默认关闭，即安装完成后删除该分区；它与Android的数据分区相邻时，空间并入数据分区。

在双系统机器上选择"保留现有系统"或"重新安装Android"时，确认页上可以选择开机默认启动的系统，每次默认预选Android（原本默认启动Windows的机器重新安装时请留意重新选择），详见[双系统](#双系统)。

### 安装失败时

请使用安装器的"保存日志"功能，把日志保存到U盘上（Windows能分配盘符的FAT32或exFAT分区）。日志保存在名为`gaokun3-logs-<时间>`的文件夹中，报告问题时请附上整个文件夹。整个写入ISO的U盘上没有可以保存日志的分区，需要另插一个U盘。Live安装器不会自动把日志写入安装介质，关机后日志即丢失。

### 分区布局

清除整个磁盘后，硬盘上的分区如下：

| 分区 | 大小 | 用途 |
|---|---|---|
| `esp` | 300 MiB | 开机菜单和各槽位的内核 |
| `misc` | 4 MiB | 记录A/B槽位的状态 |
| `metadata` | 32 MiB | Android的元数据 |
| `boot_a`、`boot_b` | 各64 MiB | 内核和启动镜像，A/B两份 |
| `super` | 12 GiB | 系统分区，A/B两份 |
| `userdata` | 剩余全部空间 | 用户数据 |

保留现有系统时，除`esp`外的分区建在未分配空间中，与Windows共用原有的EFI系统分区。

## 首次开机

首次开机大约需要两到三分钟，之后按开机向导完成设置即可，不需要运行额外的脚本。

### 此设备未经Play保护机制认证

本系统不在Google的认证设备名单中，Play商店会提示"此设备未经Play保护机制认证"，部分应用在登记之前会拒绝安装。登记是免费的，每台设备只需要做一次：

1. 在平板上登录Google账号。
2. 读取设备的Android ID。目前需要在电脑上通过adb运行本仓库中的脚本：

   ```sh
   bash scripts/google/gsf-android-id.sh
   ```

   这个ID存放在Google Play服务的私有目录中，读取需要root权限。请先安装ReSukiSU管理器，为Shell授予root权限，脚本会自动使用它。adb的设置方法见[常见问题](FAQ.zh-CN.md)。
3. 用同一个Google账号打开<https://www.google.com/android/uncertified/>，填入这个ID并登记。
4. 等待几分钟，然后清除Google Play商店的存储数据（也可以运行`adb shell pm clear com.android.vending`）。

恢复出厂设置或清除Google Play服务的数据之后，ID会改变，需要重新登记。

登记之后，Play Integrity仍然无法通过。它是部分银行和支付应用使用的更严格的检测，要求锁定的bootloader和Google签名的系统，而本机必须关闭Secure Boot才能运行本系统。依赖Play Integrity的应用在本系统上无法使用。

## 系统更新

在"设置 → 系统 → 系统更新"中检查并安装更新，内核也随系统一起更新。更新会写入另一个槽位，写入期间可以照常使用，重启后生效。网络不畅时，也可以通过其他途径下载OTA包，放到平板的内部存储中，在同一界面中使用"安装本地更新"功能。

如果更新后的系统反复无法完成启动，开机时会自动退回上一版本，并在进入系统后通知你。如果系统卡住而没有自动重启，请长按电源键强制关机后再开机。

> **更新后无法退回上一版本。**新版本首次成功启动后，上一版本的系统即被合并覆盖。开机菜单中仍会列出另一个槽位的条目，但选择它只会白白失败一次开机。大版本更新（例如从Android 16到17）还会在首次启动时升级用户数据，旧版本即使能启动，也可能无法使用这些数据。如需退回旧版本，只能用Live安装器重新安装，并且很可能需要清除数据。更新前请备份重要数据。

## 开机菜单

每次开机时会显示开机菜单，默认停留5秒，不做选择则进入默认系统。可以用机身音量上/下键选择、电源键确认，或连接键盘盖用方向键和回车操作。菜单中主要有以下几项：

| 条目 | 说明 |
|---|---|
| `Android` | 默认启动的Android |
| `Android fastboot / boot menu` | 进入fastboot模式，见[fastboot](#fastboot) |
| `gaokun3 installer` | 本机磁盘上有安装器分区时出现，启动Live安装器 |
| `Windows Boot Manager` | 双系统时出现，进入Windows |

菜单中还有按槽位列出的Android条目和上一版启动器的条目，用于排查问题，平时不需要选择。

### fastboot

在开机菜单中选择`Android fastboot / boot menu`，或在电脑上运行`adb reboot bootloader`，即可进入fastboot模式。屏幕上会显示`FASTBOOT MODE`、当前槽位和USB连接状态。

- 数据线需要插在**靠近电源键**的USB-C口，另一个口不支持fastboot。
- 在装有Android SDK Platform Tools的电脑上，可以使用`fastboot devices`、`fastboot getvar all`、`fastboot oem device-info`（查看硬盘、分区、A/B和启动入口的状态）、`fastboot reboot`和`fastboot reboot bootloader`。
- 在平板上可以用音量键移动选项，用电源键确认。

刷写功能（`fastboot flash`）尚未在实机上测试，用电源键确认选项也尚未经实测。需要重新写入系统时，请使用Live安装器。

### 双系统

双系统时，开机默认进入的系统可以在安装时选择，之后可以在Android的"设置 → 系统 → 启动选项"中修改。如果选择默认进入Windows，安装完成后的前两次开机仍会进入Android，以便完成首次设置。Android的"启动选项"中还可以直接重启到Windows。这些功能尚未经过系统的测试。

重装Windows时建立的100 MiB EFI分区容量不足，安装器不支持这种分区布局。

需要卸载Android时，请使用Windows安装器，见[卸载](#卸载)。

## 清除数据（恢复出厂设置）

设置中的"清除所有数据（恢复出厂设置）"尚未在实机上验证，需要清除数据时请使用Live安装器的"重新安装Android"，步骤见[常见问题](FAQ.zh-CN.md#清除数据)。

## 无法开机时

| 现象 | 处理方法 |
|---|---|
| 开机后黑屏，没有出现开机菜单 | 确认Secure Boot已经关闭 |
| 开机直接进入Windows，没有出现开机菜单 | 见[常见问题](FAQ.zh-CN.md#开机直接进入了windows没有出现开机菜单) |
| 更新后选择了另一个槽位的条目，机器随即重启 | 正常现象，旧版本已被合并覆盖，见[系统更新](#系统更新) |
| 固件的启动菜单里看不到U盘，或华为官方恢复无法启动 | 早期版本会把内核崩溃记录写进固件存储，存储被占满后会出现这种情况，主板并没有损坏。从1.0.0-rc.3起不再写入，已有的记录需要按[issue #56](https://github.com/vahiru/gaokun-android/issues/56)手动清理一次 |
| Android无法启动 | 见[常见问题](FAQ.zh-CN.md#开机一直重启或卡住怎么办) |

## 报告问题

请通过[issue表单](https://github.com/vahiru/gaokun-android/issues/new/choose)提交问题，提交前请先阅读[issues.md](../issues.md)。日志比文字描述更有帮助：Android能够启动时，最好附上`adb bugreport`生成的压缩包。其中包含Wi-Fi名称、账号名、已安装的应用等个人信息，公开上传之前请先检查。各类日志的获取方法见[常见问题](FAQ.zh-CN.md)。
