# 手写笔（华为M-Pencil）

跟踪：issue [#26](https://github.com/vahiru/gaokun-android/issues/26)。

## 功能与适用范围

支持二代和三代M-Pencil：压感、悬停、倾斜；笔身侧边双击可以在笔与橡皮擦（Android的`TOOL_TYPE_ERASER`）之间切换，或作为侧键单击，默认不响应（Android不提示当前工具，不支持橡皮擦的应用在切换后看起来像是写不出笔迹）；系统休眠恢复后照常可用；电量显示在"设置 → 已连接的设备 → 触控笔"，电量低时系统提醒充电。"设置 → 已连接的设备 → 手写笔设置"（Parts的`StylusSettingsActivity`）在标题下显示已连接的笔的型号，可以调节四档笔迹平滑，把侧边双击设为切换橡皮擦或侧键单击，也可以断开与笔的连接。

一代M-Pencil（CD52）使用另一种协议（HPP2），驱动不支持；三代M-Pencil的日常使用效果尚未经过系统实测，压感若超过4095会被截断。

## 数据通路

笔的数据来自两处，由用户态守护进程`gk3pend`合成为一支`uinput`触控笔。坐标与触摸屏是同一套像素坐标，以1/16像素为单位上报（`ABS_X` 0–25599、`ABS_Y` 0–40959）。

* **触摸从片（位置、悬停、倾斜）**：屏幕的触摸控制器是一对HX83121A，主片在`spi6`（由`himax-spi`驱动，负责手指），感应笔的级联从片在`spi20`（ACPI中的`THPB`/`HIMX0002`），中断在GPIO 39，没有独立复位线。初始化写入`raw_out_sel = 0xF6`与rawdata地址`0x5AA5`后，从片在中断上输出339字节的帧，包含笔尖（TX1）与笔尖上方环形电极（TX2）各自的锚点和9×9网格。位置与悬停取自TX1，倾斜取自TX1与TX2的偏移。
* **笔MCU（压感、侧键、电量）**：平板内部USB设备`12d1:10b8`是笔的接收端：
  * 接口0的`hidraw`（报文`0x55`）：压感，每包4个`u16`槽。笔一拿起报文即开始发送，`gk3pend`用它提前唤醒从片。
  * 接口1的厂商bulk通道（OUT `0x02`、IN `0x85`）：侧边双击（事件`0x2F`）、电量（`0x08`）、充电状态（`0x09`）、型号（`0x00`）、固件版本（`0x03`）、笔的连接状态（`0x71`）以及新笔的配对请求（`0x15`）。主机需先发送`0x7101`、`0x7701`查询才会收到事件（型号另需空载荷的`0x0000`查询，见下文“连接状态与断开连接”），ACK对照表中的事件须回ACK（`0x8001`），否则后续事件会阻塞。协议见EGoTouchRev的`penevt/BTMCU_PROTOCOL.md`。

### 电量与充电状态

`0x08`上报电量、`0x09`上报充电状态。吸附充电期间笔会自行上报电量（随电量变化，间隔约40秒），不需要主机查询；`0x09=1`只表示笔报告的充电状态位，电量已满时仍可能为1。主机主动查询`0x0801`/`0x0901`在亮屏时都能得到回复，熄屏时`0x0801`没有回复。

## 设计取舍

* **解算放在用户态**：压感、侧键和电量只能经USB从笔MCU取得，因此内核驱动只负责交出从片原始帧，由`gk3pend`在一处合并解算（沿用EGoTouchRev逆向出的HPP3步骤）。
* **一欧滤波（One Euro filter）替代直线拟合**：解算出的原始位置每帧有零点几个像素的抖动，慢速书写时放大呈锯齿。`gk3pend`采用截止频率随速度升高的一欧滤波，慢写时多平滑、快划时几乎不增加延迟，并以1/16像素上报亚像素精度。原厂后处理链中的直线拟合（`LinearFilterProcess`）未采用：写字时很少触发，反而会把慢速画出的缓弧拉成折线。
* **从片跟随复位与空闲降频**：从片没有复位线，主片每次复位（熄屏亮屏、`himax-spi`自恢复）都会使从片丢失配置，因此驱动在帧头异常、连续读失败或亮屏无帧时自动重初始化。`himax-spi`让触摸芯片进入IDLE后，从片约每3秒才送出一帧，此时只要10秒内收到过帧头正确的帧，驱动就不把读取时没有新帧或1秒内无帧视为异常；笔使用后3秒内`himax-spi`不请求IDLE。无笔超过`idle_after_ms`后关闭中断改为低频轮询，`gk3pend`收到笔MCU报文时写`/dev/gk3_pen`立即恢复中断。
* **USB休眠恢复**：笔MCU在收到`SET_FEATURE(REMOTE_WAKEUP)`后会按接口扣住IN报文，直到该接口收到`SET_IDLE`或OUT传输才放行。接口0（压感）绑定`hid-generic`，靠`patches/kernel/input/0022`新增的`HID_QUIRK_IDLE_ON_RESUME`在恢复时发送`SET_IDLE`；接口1（侧键与电量）由`gk3pend`在检测到休眠恢复后重新发送查询握手。
* **配对新笔**：尚未与本机配对的笔吸附到充电位置后，笔MCU上报配对请求（`0x15`，载荷为笔的型号）并等待主机确认；没有这一步，笔不会连接，只能悬停而无法书写。Windows中由华为电脑管家（`McuDevCo.dll`）立即回`0x2E`并弹窗询问，用户同意后发送`0x1501`（`0x1500`为删除配对，`0x1502`为取消），笔MCU随后以事件`0x16`上报结果（1为成功），笔照常连接；收到`0x29`时关闭弹窗，不再确认。电脑管家只连接其型号表中的笔，且确认前先将当前连接的笔报告为断开，即同一时间只连接一支笔；吸附另一支笔后，原来的笔是否需要重新配对尚未实测。`gk3pend`将吸附视为同意：对二代、三代笔回`0x2E`后1.5秒发送`0x1501`，其间收到`0x29`或`0x16`、或者重新打开笔MCU（休眠恢复、USB出错）时放弃；其他型号（包括一代笔）不予确认；每分钟最多响应3次请求，以免配对失败后笔MCU反复请求时陷入循环。
* **笔的初始化参数**：笔会一直保留主机最后发给它的初始化参数（`0x7D01`，由笔MCU转发给笔），这组参数决定笔尖信号的发射时隙。华为每款设备各有一组（THP服务`TSAPrmt.dll`中按机型的参数表，本机BOE与CSOT面板共用一组），所以连过其他华为设备、或收到过其他取值的笔，回到本机后发射时隙与从片的扫描对不上：从片每个显示帧的两次扫描中，第二次只能读到笔附近隔一列的电极，这一帧的位置落到格子中央，笔迹出现最多一列宽的锯齿；平板关机、重启和重新配对都不会消除。Windows上华为THP服务在笔每次连接（“hpp3 on”）时发送本机参数，所以Windows下总是正确的。`gk3pend`照此在笔MCU报告笔已连接（`0x71`为1）时发送同一组参数，包括每次握手（启动、休眠恢复或出错后重新打开笔MCU）的回复，因为休眠期间笔重新连接的事件只会体现在恢复后的握手回复中；发送成功后，若未断开且未重新打开笔MCU，距上次发送不足2秒的`0x71`为1不再重复发送；发送失败时，下一次`0x71`为1会重试。不在`0x7B`时发送，因为笔在每次`0x7D01`之后（以及屏幕状态变化后）都会回一个`0x7B`，会形成循环。参数取自参数表的Gaokun项（字符串`3333,3333,2e7,412,258,411a,0f,1`），其中`0f`换算为`0F 00`，即N与类型两个字节；THP服务发送前会把偏移13、14的两个字节（类型与末字节）置为1。按字符串原样换算得到的类型0会使笔保持锯齿状态。
* **未配对提示与配对完成通知**：笔尖信号由笔自身的电池驱动，与蓝牙配对无关，因此未配对的笔仍能被从片感应到，只是收不到它的压感。已配对的笔从拿起起就持续发送压感报文（悬停时为0），所以当锚点峰值达到接触强度（至少3000；悬停一般低于约2500，接触高于约3000）累计2秒、而2秒内没有任何压感报文时，`gk3pend`判定有未配对的笔在书写，将`vendor.gaokun3.pen_unpaired`设为1；已配对的另一支笔放下后约20秒才停发压感报文，此后换用未配对的笔才会触发。压感节点或笔MCU未打开时，以及二者重新打开或系统休眠恢复后的5秒内不做判断。收到压感报文、配对完成、系统休眠恢复，或者系统未休眠时10分钟内不再出现这种情况时恢复为0。每完成一次配对（`0x16`为1），`gk3pend`先撤销提示，再把`vendor.gaokun3.pen_paired`设为“单调时钟的毫秒数,代数”。Parts的`StylusNotifier`在亮屏时每3秒读取这两个属性，发出“发现未配对的M-Pencil”提示和“已连接到M-Pencil 2/3”通知（点按打开“手写笔设置”，同一次配对只通知一次），通知类别为“手写笔”。电量耗尽的笔不发出任何信号，不会触发提示。
* **连接状态与断开连接**：笔MCU只在笔吸附或连接时主动上报型号（`0x00`），握手的回复里只有连接状态（`0x71`），所以`gk3pend`启动、休眠恢复或重新打开笔MCU之前就已连接的笔，型号无从得知。华为电脑管家（`McuDevCo.dll`的`IsPenBaseInfoComplete`）在没有型号时发送空载荷的`0x0000`查询，`gk3pend`照此在每次握手后查询一次，笔MCU随即回报`0x00`。`gk3pend`据`0x71`与`0x00`设置`vendor.gaokun3.pen_conn`：未连接（`0x71`为0或尚未上报）时为0，已连接时为笔的代数2或3，型号未知时为1。设置页每秒读取一次，在标题下显示“已连接到M-Pencil 2/3”或“当前未连接M-Pencil”；已连接时，页面最下方显示红色的“断开连接”按钮。确认后，设置页把非持久的`sys.gaokun3.pen_unpair`在1、2之间交替设置（Parts设不了vendor属性），`gk3pend.rc`按字面值转为`vendor.gaokun3.pen_unpair`，`gk3pend`看到它与上一次看到的值不同（启动时的值视为已看到）就发送`0x1500`（删除配对，与电脑管家的`PenDeletePair`相同）。笔MCU随即报告`0x71`为0，笔只能悬停，吸附到充电位置后重新配对。两个属性都不持久，开机不会重放。笔MCU重新打开的间隙收到的请求直接放弃，设置页仍显示已连接，可以再次操作；笔MCU无法打开时（例如从USB上消失），`pen_conn`改为0，设置页不再显示笔。笔长时间闲置后是否报告未连接尚未实测。
* **笔尖松动提示**：笔尖电极的信号经可拧下的笔尖传到屏幕。笔尖拧松后，接触时的TX1锚点峰值降至原来的四分之一或更低（中位数约3300降至400–1000），笔身环形电极的TX2基本不变（约1000），坐标噪声增大约3倍，压感仍然正常。以CD54R实测，笔尖拧松1圈以内信号与笔迹均正常，拧松约1¼圈时TX1在一笔之内骤降，笔迹随之异常。正常书写时TX1在2000–9000之间，TX2/TX1为0.08–0.6；个别笔画的TX1会低于1500或比值超过1，但不会同时出现。`gk3pend`把TX1低于1500且TX2高于TX1的80%的接触帧计为弱帧，至少10帧（约40–50毫秒）、且多数为弱帧的一笔计为松动；松动的笔尖偶尔会有一两笔恢复正常，因此最近8笔中有6笔松动时才将`vendor.gaokun3.pen_nib_loose`设为单调时钟的毫秒数，降至1笔及以下时恢复为0。休眠恢复不重置判断；`gk3pend`重启时属性恢复为0并重新判断，笔尖仍松动时再写8笔会以新值重新提示。Parts的`StylusNotifier`据此发出“手写笔”类别的笔尖松动提示，同一次判定只提示一次，恢复为0时撤下。按现有录制，TX1骤降后的第6–7笔即发出提示，重新拧紧后的第7笔撤下，1347笔正常书写中没有误报。
* **电量节点挂载方式**：驱动注册的`power_supply`节点`m-pencil`故意不挂父设备——Android `EventHub`为虚拟`/sys/devices/virtual`下的`uinput`设备查找电池时，会将无父设备的设备级电池关联为触控笔电池，并由单独的SELinux类型`sysfs_gaokun3_pen_battery`放行`system_server`读取。
* **面板列间距、列读出时差与强峰区域**：
  * **列间距**：BOE屏两端变宽、中间变窄，CSOT屏相反。`gk3pend`读取设备树中面板的`compatible`自动选表（日志打印`column pitch boe|csot|even`）。
  * **列读出时差**：从片偶数列比奇数列晚约1 ms读出，导致斜线出现周期一到两列的规则波浪。`pos_skew()`按采样时隙的速度补偿时差，不增加延迟。
  * **未刷新帧与强峰区域**：`stale_frame()`跳过中心3×3读数未刷新的帧（最多连跳一帧）。CSOT屏部分行存在整行同相波动噪声，默认启用只取四连通高值单元的"强峰区域"以减小行噪声混入；BOE屏上保持原区域算法。

## 已知限制

* **防误触**：笔在感应范围内时Android会屏蔽同窗口的手指触摸；笔离开感应范围但手掌仍搭在屏上时，由触摸驱动在“设置 → 显示 → 防误触模式”开启（`daily`预设）下的[手掌识别](palm-rejection.md)处理。
* **边缘与斜线细小起伏**：离屏幕边缘约2 mm内的坐标会被压向边线；慢速用尺画斜线仍有约±0.1 mm随倾角变化的格内误差，单一修正表无法消除。
* **CSOT屏行噪声**：在一台CSOT屏上测得第12–19行原始噪声约为其余行的2倍，强峰区域可减轻但无法完全消除。
* **离位判读**：`0x09`由1变为0同时出现在“充满停充”和“笔离开充电位”两种情形，其后的`0x72`变化也几乎相同，主机侧没有独立的离位信号；`0x09`与`0x72`的先后顺序存在反例，不能作为判据。
* **`0x72`不是在位标志**：它是`PEN_CUR_STATUS`模式位，笔离机静置时仍会在`0x01`与`0x02`之间变化。
* **USB枚举不是在位标志**：`12d1:10b8`常驻机身，笔不在机身上时它的三个接口与两个`hidraw`仍然存在。

## 调试

* **日志与统计**：`gk3pend`日志输出在`dmesg`（含面板类型、电量、重握手、设置变更）；从片计数见`/sys/kernel/debug/gk3_pen/stats`，驱动参数在`/sys/module/himax_hx83121a_pen/parameters/`。
* **休眠恢复检查**：`/sys/module/usbhid/parameters/quirks`应含`0x12d1:0x10b8:0x21000000`，`/sys/bus/usb/devices/3-3/quirks`应为`0x0`；`hidraw`无压感报文时检查`dmesg`有无`SET_IDLE on resume failed`。
* **手动调参与录制**：`stop vendor.gk3pend`后以root运行`/vendor/bin/gk3pend`（`-pf`调滤波、`-sk`调列时差、`-ns`禁跳帧、`-pr`/`-lr`切换峰值区域、`-rec FILE`录制原始帧），测试完毕后`start vendor.gk3pend`。
