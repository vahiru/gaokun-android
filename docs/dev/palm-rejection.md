# 触摸屏的手掌识别

跟踪：issue [#29](https://github.com/vahiru/gaokun-android/issues/29)。

## 功能

在日常触摸模式（`daily`）下，当写字、画画时手掌或手侧压在屏幕上、整只手平放或指节擦碰屏幕时，驱动不再把手的各部分误报为手指触点；已经上报、随后才识别为手掌的触点，会通过`MT_TOOL_PALM`撤回，Android的`InputReader`随即向应用发送`ACTION_CANCEL`（单指）或带`FLAG_CANCELED`的`ACTION_POINTER_UP`（多指）。

判断只使用40×60的电容网格数据（`patches/0081`、`patches/0082`），不依赖手写笔。屏幕上没有手掌时，纯手指操作的结果与原算法逐帧相同。

## 核心机制与设计取舍

原有的`hx_reject_palms()`只按单帧连通域的面积、信号总和、长宽比或低密度判断，只能过滤掉掌根，而同一只手弯曲的手指、指节和小鱼际在网格上是和指尖差不多大的孤岛。为此驱动在`hx-algo.c`中增加了**手的位置图（`hand_age[]`）**，记录每个网格单元最近一次属于手掌是几帧以前：

* **碎块跟着手走**：一旦某个连通域被判为手掌，其外扩`hand_margin`格写入位置图；落入位置图的峰值在展开为触点前即被丢弃，且**该峰值所在的整个连通域也会并入位置图**。这样同一只手的指节、手侧碎块会持续被识别为手，直到整只手抬起，也不会占满10个触点槽位。
* **一起落下（同时性窗口）**：整只手平放时，手指往往比掌根早几十毫秒接触屏幕。当屏幕从无手掌状态新出现手掌时，算作一次"落下"，在落下前后`hand_land_frames`帧（约100 ms）、距离`hand_land_dist`格（约11 cm）以内的峰值、连通域和刚产生的跟踪都会归入同一只手并撤回。
* **已经按住的手指不受影响**：按下已超过`hand_land_frames`帧的触点，只有当它当前所在格子直接变成掌根（`hand_age == 0`）时才会被撤回；手指周围±2格的峰值只要当前帧不属于手，即使仍在位置图的历史保留期内也照常保留。因此按住手指后再放下手掌，或手指划过手掌刚离开的区域，都不会断触。
* **事后撤回，而非推迟上报**：如果等确认不是手掌再上报，每一次正常点击都会增加按下延迟。因此驱动照常立即上报按下，事后识别为手掌时先发一帧`ABS_MT_TOOL_TYPE = MT_TOOL_PALM`再释放，由Android取消本次触摸。
* **峰值超过10个时取最强10个**（`patches/0081`）：`hx_detect_peaks()`按信号从弱到强排序，原驱动直接截取前10个，导致整只手压在屏上产生大量弱峰值时，真正强的手指峰值反而被丢弃。现改为截取最强的10个。

## 已知限制

* **掌根未触屏时无法建图**：手悬空很轻地搭着、没有任何一块连通域达到掌压阈值时，位置图不会建立，指节碎块仍会按手指上报。
* **另一只手恰好同时按下**：手掌落下前后约100 ms、周围约11 cm内恰好按下的另一只手手指，会被当成同一只手撤回。
* **游戏模式下默认关闭**：打音游或手柄式握持时，贴着屏幕边缘平放的拇指容易达到掌压面积阈值，位置图还会连带屏蔽其周围约9 mm、抬起后约300 ms内的点击。因此`bin/gaokun3-touch-mode.sh`在`game`预设下将`/sys/bus/spi/devices/spi0.0/algo/hand_enabled`设为`0`（`daily`预设设为`1`）。
* **依赖应用正确处理`ACTION_CANCEL`**：被撤回的触点在撤回前已向应用发送过`ACTION_DOWN`，若应用忽略`ACTION_CANCEL`仍可能留下笔画点。

## 调试与回放

* **运行时参数与统计**：参数（`hand_enabled`、`hand_margin`、`hand_hold_frames`、`hand_land_frames`、`hand_land_dist`）与计数器（`hand_lands`、`hand_peaks`、`hand_cancel_map`、`hand_cancel_land`）均在`/sys/bus/spi/devices/spi0.0/algo/`下；`logcat`中搜索`Canceling pointer`可查看Android侧撤回记录。
* **离线录制与仿真对比**：在设备上用`gk3trec`录制原始电容网格与evdev事件，在宿主机用`hxsim`直接链接内核树的`hx-algo.c`回放比对，用法见[`scripts/touch/README.md`](../../scripts/touch/README.md)。
