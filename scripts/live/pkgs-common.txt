# rescue 与 live 共同的包（Debian 13 trixie 包名；2026-09-25 逐个 apt-cache 核实过）。
# ★ 每一个都要说得出"没有它会怎样"。镜像里多一个包就多一个会坏的东西。
# ⚠️ 由 build-rootfs.sh 以 --no-install-recommends 装：推荐包不跟进来，要的就写在这里。

# —— init 与基础 ——
# ★ systemd-sysv 提供 /sbin/init；initramfs-init 最后 switch_root 到它
systemd-sysv

#   才知道一个设备是触摸屏，没有它界面画得出来但一个触摸事件都没有（Alpine 版 2026-08-23 踩过）
udev
dbus
kmod
procps
iproute2
iputils-ping
less
file
strace
pciutils
usbutils
# ★ initramfs 用的静态 busybox 从这里抠（build-initramfs.sh 要求静态 aarch64）

wpasupplicant
iw
wireless-regdb
dhcpcd-base
# ★ ath11k 的固件（WCN6855 hw2.0 + hw2.1）。在 non-free-firmware 里，build-rootfs.sh 会开这个组件

openssh-server

avahi-daemon
libnss-mdns
ca-certificates
curl
wget
rsync

util-linux
e2fsprogs
dosfstools
f2fs-tools
# ntfsresize：双系统缩 Windows 分区
ntfs-3g
nvme-cli
# simg2img：后端已改用 gk3-unsparse.py（simg2img 喂管道会失败），留着给手工排障
android-sdk-libsparse-utils
# ★ python3：gk3-unsparse / gk3-bootimg 两个辅助脚本
python3
zstd
xz-utils
efibootmgr
# ★ systemd-bootaa64.efi：gk3_apply 往目标机 ESP 上装的就是镜像里这一份（/usr/lib/systemd/boot/efi）
systemd-boot-efi
